**Pre-release alpha** - a fix-up build for VOIDWRAP RUN v0.3.0. Expect bugs and changes.

## How to play
Same as before. Windows: download the file ending in `...-windows-setup.exe` from this release and double-click it (click "More info" and "Run anyway" if Windows asks), or use the zip: **extract it**, then double-click **VOIDWRAP RUN**. If the window stays empty or white, double-click **PLAY-IN-BROWSER**. Step-by-step help: `HOW-TO-PLAY.md` inside the download or [in the repository](https://github.com/heylyfe/VOIDWRAP_RUN/blob/main/HOW-TO-PLAY.md).

## What's fixed in this alpha
- **Smoother game**: the screen no longer redraws its menus and counters twenty times a second, so frame rates are steadier.
- **Pick your name**: type a name on the title screen. It is remembered next time. Without one, you get a name like "Player-4821".
- **Cleaner respawns**: when you respawn after a fall or a lost life, keys you pressed just before no longer carry over and push you off the spawn.
- **Friends leaving no longer freeze the lobby**: if a friend disconnects while you are all choosing hunters and upgrades, the vote now finishes without them.
- **Internet hosting stays open**: the automatic router setting for "Play with friends" is now renewed in the background, so long sessions (over 2 hours) keep working. If your router stops allowing it, the host panel tells you.
- **Host panel works in development mode** too, not only in the finished game.
- **No leftovers after a restart**: a late update from your previous run can no longer flicker into the new run.
- **Bulwark's ability** is now described correctly in the game's notes (Aegis Bloom: brace, ward, pulse).
