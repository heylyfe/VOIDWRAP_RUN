# v0.26.0-alpha.1 — Refinement Cycle 14

A cycle with no game changes. Every ticket is measurement, because three of the
audits were passing for reasons that had nothing to do with the game being correct.

## Every pattern must reach a level

Three shipped bugs had the same shape: a piece that parses, validates, is counted by
`validate-content`, and never appears in a generated level. The strict-parse count
assertion catches two of them; an *eligibility* filter is invisible to it, and
invisible to every rate metric, because a piece with no placements contributes to no
rate.

New metric `7.catalog-coverage` reads the catalog ids from `design/`, collects every
id that reaches a plan, and fails on any id that never appears. Negative-tested with
a deliberately ineligible pattern: it fails and names the offender. **140 / 140
patterns reach a level.**

## Four metrics were weaker than their own names

| metric | was | now |
|---|---|---|
| `4.greater_curse_rate` | counted *definitions* | drafts over 50 levels in `[3, 8]`, pool deep enough for no forced repeat |
| `5.hazard_tags` | `total > 0` (one placement in 6,000 levels) | every tag in `>= 20 %` of levels |
| `7.patterns_per_level` | `median >= 3` | `median in [10, 60]` |
| `3.pedestal_pool` | `pool@1 >= 3` | 6 conditions across levels 1/10/20 plus capacity |

`4.greater_curse_rate` was the worst: named `_rate`, measured a count of
definitions, so a run could reach level 50 without ever being offered a greater curse
and the metric would still pass.

## A check that could never fail

`6.enemy-frequencies.never-offered` reported **PASS** whenever the enemy roster was
absent — and it was always absent, because the dump carries generic spawn markers,
not enemy types. A metric that can never fail, printed as a pass, is worse than no
metric: it looks like coverage.

It now reports **SKIP** with a reason and points at the check that can measure the
thing: `3.pedestal_pool` in the economy audit, which reads the registry directly and
now asserts that **every enemy is reachable by level 20 in all four modes** and that
**every enemy has `selection_cap >= 1`**.
