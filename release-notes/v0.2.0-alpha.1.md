**Pre-release alpha** - the second playable build of VOIDWRAP RUN. Expect bugs and big changes.

## How to play
Download the file for your system below (Windows: `...-windows.zip`), **extract it** (right-click -> "Extract All..."),
then double-click **VOIDWRAP RUN**. The game opens in its own window - no web browser needed. If the window stays
empty or white, double-click **PLAY-IN-BROWSER** instead. Step-by-step help for every click: see `HOW-TO-PLAY.md`
inside the download or [in the repository](https://github.com/heylyfe/VOIDWRAP_RUN/blob/main/HOW-TO-PLAY.md).

Windows may say "Windows protected your PC" the first time: click "More info", then "Run anyway".

## What's new in this alpha
- **The game runs in its own window** on your desktop - there is no black window for normal play. `PLAY-IN-BROWSER` stays as a backup that runs the game in a web browser.
- **Classes**: at the start of a run each player picks Striker (dash), Grappler (auto-aimed grapple), Blinker (short teleport) or Glider (extra mid-air jump and gliding). The class stays for the whole run. Ability on Shift or the right mouse button.
- **A lobby shop** from level 2 on: spend the team's golden-gift gold on extra lives, rerolls and small permanent boosts.
- **Altars**: walk up to a stone shrine and press E for one random upgrade and one random curse. Each altar works once.
- **Level events**: High Rise (climbing platforms), Slick Ice (you slide) and Crumbling (platforms fall away and come back).
- **Three new hunters**: Bolt Sentry (stationary shooter), False Gift (a trap that chases you) and Crumble Wisp (crumbles nearby platforms).
- **Playing with friends from your own computer**: friends join on your Wi-Fi, or anywhere else when the game can set up your router automatically (UPnP) or you forward port 7879. Friends only need a web browser - or the game itself. Up to 8 players.

## What the first alpha already had
- Lobby on a shared spawn platform: vote on which **enemies hunt you** and pick an **upgrade or curse**
- **Randomly generated levels** of checkerboard roads in a coloured void - a new map every level, every map tested to be completable
- Collect the gifts -> **golden gifts** (money for the shop) appear and the **beacon** opens -> back to the lobby for the next pick
- Lives, and finished or out players become invisible flying spectators
- Running, jumping, falling, landing and dashing animations; four visual themes with their own screen filter
