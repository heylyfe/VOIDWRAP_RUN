# v0.28.0-alpha.1 — Refinement Cycle 16

A diagnosis cycle. No game code changed.

## Why the automated playthrough never reaches level 2

`level-progression` has been skipped for many cycles with the note "bots fall before
level 2". Cycle 15 established the falls are navigation, not collision. This cycle
found out why the navigation fails.

The bot is not a random walk — it has nearest-gift steering with hysteresis, a
platform-graph route, an edge probe, air control and stuck detection. So the failure
needed measuring:

| clients | seconds | deaths | best client's gifts |
|---|---|---|---|
| 1 | 120 | **0** | 12/46 |
| 1 | 280 | 1 | 7/46 |
| 2 | 90 | 2 | 5/52 |
| 4 | 90 | 3 | 14/64 |
| 8 | 90 | 7 | 40/88 |
| 8 | 240 | 8 | 38/88 |

Deaths scale with client count because gift count scales (46 → 88) and the bot's
herd-spreading sends bot *i* to the *i*-th nearest gift, so more clients means longer
routes. More time does not help: 240 s plateaus at 38/88, the same as 90 s at 40/88.

**Two blockers, both real:**

1. **A run starts with 0 spare lives.** The first fall ends it, and the check needs all
   eight bots to survive. This is the deferred balance decision, not a defect.
2. **The edge probe's failure path is "blacklist the gift, hold still."** A bot whose
   remaining gifts are all behind gaps it cannot probe stands still forever.

Ruled out: collision (Cycle 15: zero seam falls), player-vs-player pushing (the sim has
no player-player collision), a time limit, gift scarcity.

The check stays parked, but the skip line now prints the reason, so the gate output
points at the balance decision instead of implying a bug.

## Tuning notes for the later balancing pass

- **Starting lives = 0 is now the single largest obstacle to automated coverage.**
  Voting, the shop and altars all sit behind level 2, and none of them can be exercised
  end-to-end until a run survives one fall. Starting at 1 would unblock three checks.
- `5.reference-scale`'s `minExtent` formula over-estimates the forced extent for
  stepped terraces and for chunks whose ramps sit inside their deck. The metric passes
  at 2.11% against a 10% ceiling, so this is audit hygiene, not a defect.
