**Pre-release alpha** — a bug-fix build for VOIDWRAP RUN v0.3.1. Expect bugs and changes.

## How to play
Same as before. Windows: download the file ending in `...-windows-setup.exe` from this release and double-click it (click "More info" and "Run anyway" if Windows asks), or use the zip: **extract it**, then double-click **VOIDWRAP RUN**. If the window stays empty or white, double-click **PLAY-IN-BROWSER**. Step-by-step help: `HOW-TO-PLAY.md` inside the download or [in the repository](https://github.com/heylyfe/VOIDWRAP_RUN/blob/main/HOW-TO-PLAY.md).

## What's fixed in this alpha
- **Gifts can no longer be stuck in walls, jump pads or ramps.** Every gift is checked against the level's solid geometry before it is placed; a bad spot is skipped and another one is sampled. A probe over 60 generated levels (4,260 gifts) found zero overlaps.
- **Gifts glow.** Every gift now has the same bright glow the golden ones had, so none of them disappear into the dark.
- **A little sparkle when you pick a gift up**, so a pickup reads instantly even in a crowd.
- **Fog fixed.** A bad fog value could make the whole scene render with no fog or with fog everywhere; it now falls back to a clear, far-out setting.
- **Upgrades and curses no longer get mixed up** in the run status chips: each one is filed by what it actually is, not by which list it arrived in.
- **The glider has a real model** — a proper hang-glider with spars, wing panels and a frame, instead of two flat planes.
- **Enemies scale with the level**: one extra hunter per level after level 1, capped at six extra so late levels stay playable.
- **Enemy names now say what they do**: Footprint Chaser, Orbit Dasher, Stillness Shrieker, Wall Drifter, Shell Bomber, Gift Stinger, Bolt Turret, False Gift, Floor Rotter.
- **New curse: Clustered Gifts.** Gifts gather in tighter clumps instead of spreading evenly (minimum spacing 2.0 → 1.2 units; measured mean nearest-gift distance 3.47 → 2.65 units).
