**Pre-release alpha** — ramps replace every stair. Expect bugs and changes.

## How to play
Same as before. Windows: download the file ending in `...-windows-setup.exe` from this release and double-click it (click "More info" and "Run anyway" if Windows asks), or use the zip: **extract it**, then double-click **VOIDWRAP RUN**. If the window stays empty or white, double-click **PLAY-IN-BROWSER**. Step-by-step help: `HOW-TO-PLAY.md` inside the download or [in the repository](https://github.com/heylyfe/VOIDWRAP_RUN/blob/main/HOW-TO-PLAY.md).

## What's new in this alpha
- **No more stairs.** Every staircase in the game is now a ramp. You walk up and down them at full speed without jumping, and you never lose your footing on the way down.
- **Ramps are real geometry**, not a visual trick: the collision surface is a true slope, and the server and your browser compute it from the same shared code, so what you see is what you stand on.
- **Bigger, clearer platforms** at the scale of the reference art: wide walkways, height differences you can read at a glance, and slopes gentle enough to run up.
- **Ramps look like ramps** — solid wedges with the same surface material, ice tint and crumble behaviour as the flat platforms.

## Under the hood
- Four new platform kinds (`RAMP_PX`, `RAMP_NX`, `RAMP_PZ`, `RAMP_NZ`) encode the slope direction in the existing platform kind byte, so the wire format did not change shape and every existing platform kept working.
- The slope lives in the shared `sim` crate, which compiles to both the server and the browser's prediction, so the two can never disagree about where the ground is.
