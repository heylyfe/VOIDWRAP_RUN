# VOIDWRAP RUN v0.21.0-alpha.1 — Fix & Test-Tools Wave v2

Eleven tickets, T-106 → T-116. This wave is all fixes: the owner's ramp
complaints, generation consistency, shop scaling, the glider, black gifts, a
tester build, two bug hunts, gift spawn safety, and a measured performance
pass.

## The three ramp bugs are fixed

**Walking on ramps no longer teleports you.** The bug reproduced as: climb one
ramp into the foot of the next and you snap back to the first ramp's low edge.
Two defects in the step-up path — a ramp counted as solid to its own step-up
probe, and the step-up lifted to the wrong surface when two ramps meet. Four
new regression tests cover walking up, down, across, standing still, landing
mid-slope, and ramp-to-ramp joints.

**Ramps no longer face backwards.** Orientation is derived from the anchor, and
generation now rejects a backwards ramp.

**The ramp checker follows the incline.** The material used to stretch along
the slope; it now divides the checker coordinate by the slope's cosine so the
pattern reads correctly and matches adjacent path pieces.

## Generation consistency

**7.7 % of all ramps rose into nothing** — 9,819 of 127,635, across 63 % of
levels. A player who walked up one reached a lip with no route behind it. Now
**0 of 125,871**. Nine design fragments were corrected; the tolerance constant
is deliberately the same 0.55 u as the controller's step height, so generation
and movement finally agree on what "walkable" means.

**1.96 % of gifts spawned inside solids** — 14,783 of 755,887, uncollectable,
which softlocks the collect phase. Now **7 of 755,887 (0.0011 %)**; the
residual 7 are guaranteed-fallback positions.

**The last 20 % of a level's gifts now glow with a beacon beam**, so you stop
wandering an empty level looking for one gift.

## Shop scales with income

Prices used to be flat while gift income grew, so by level 20 you bought the
whole shop every time. Prices are now a function of the level bracket, holding
**price/income constant (≤ 5 % drift)**. The cheapest item costs 1.08 levels of
income at level 1 and the same fraction at level 40.

## Visuals

**Normal gifts are black** (body `#0b0b14`, cool glow), **golden gifts are
gold** (`#ffd75e`). LURE's fake-gift glimmer now mimics the black gift only, so
the ambush still works and is never confusable with a golden or highlighted
gift. The glider has a full procedural model — spars, swept membrane, kingpost,
A-frame control bar, streamers, fold/unfold animation.

## Tester build

A dev panel (**Ctrl+Shift+D**) over a frozen 15-command manifest: spawn/despawn
enemies by registry id, switch level with a seed, grant gold, grant/remove
gifts, set phase, toggle fog, give/take upgrades and curses, trigger altars,
teleport players, read registry/pattern/vote state.

Three gates, all proven by tests: the route exists only with the dev flag or a
valid `VOIDWRAP_DEV_CODE` (constant-time compare, 5 wrong attempts per
connection then lockout); every command is rejected while more than one player
is connected; every executed command is audit-logged. The panel hides itself
when a second player joins.

## Performance — measured, then parked

| metric | value |
| --- | --- |
| server tick, 8 players | **0.03 ms/tick** at 20.0 Hz (0.06 % of the 50 ms budget) |
| level generation | **1.22 ms/level** |
| client frame | 8.8 fps under SwiftShader software rendering — **not a GPU measurement** |

The server and generation are two to three orders of magnitude inside budget.
One client-side candidate was tried and reverted because it produced no
measurable win. **If the game still feels laggy on your machine, the next step
is a GPU-side profile** — `node tools/fps-probe.mjs --seconds 20` is ready.
