## Task
1. `world.rs`: add `pub fn set_tiles(&mut self, tiles: &[TileState])` - every platform whose id appears with
   `state == TILE_GONE` stops being solid; every other platform is solid again (TILE_WARN is still solid). The
   controller's collision must ignore non-solid platforms. Keep `World::from_level` (all solid) and the existing
   public fields working; you may add a field. Tests: a player standing on a gone platform falls; restoring it works.
2. `controller.rs`, behaviour by `state.class` (unknown values behave like CLASS_STRIKER):
   - CLASS_STRIKER: the existing dash, completely unchanged (all existing tests pass untouched).
   - CLASS_GLIDER: one extra air jump on top of `tuning.air_jumps` (total still capped at TUNING_AIR_JUMPS_MAX + 1).
     Holding BTN_ABILITY while airborne and falling (vel.y < 0) caps the fall speed at GLIDE_FALL_SPEED = 3.0 and
     multiplies the horizontal air speed limit by GLIDE_AIR_SPEED_MUL = 1.15. No dash.
   - CLASS_BLINKER: BTN_ABILITY press (rising edge, like the dash) teleports up to BLINK_DISTANCE = 6.0 units
     horizontally in the input direction (move_x/move_z, normalised); with no input, along the horizontal velocity;
     with neither, nothing happens and no cooldown starts. Sweep in steps of at most 0.25 units and stop at the last
     position where the player box overlaps no solid platform (never tunnel through walls). After a blink:
     vel.y = max(vel.y, 0.0), `ability_active_frames = BLINK_FLASH_FRAMES` (6, visual only),
     `ability_dir` = the unit direction, cooldown = the tuned dash cooldown (reuse the existing dash cooldown
     multiplier and clamping). No dash.
   - CLASS_GRAPPLER: BTN_ABILITY press (rising edge, off cooldown) picks a grapple point automatically. Aim =
     input direction, else horizontal velocity, else no grapple. Candidates: for each solid platform, the point P on
     its top face (x and z clamped into the top rectangle, y = top) closest to `pos + aim * 8.0`. Valid when
     3.0 <= |P - pos| <= GRAPPLE_RANGE (14.0), P.y >= pos.y - 1.0, and the horizontal direction to P has a dot
     product >= 0.5 with the aim. Choose the valid P closest to `pos + aim * 8.0` (ties: lowest platform id).
     While grappling (`ability_active_frames > 0`, at most GRAPPLE_MAX_FRAMES = 45; store P + (0, 1.2, 0) in
     `ability_dir` as the target POINT): no gravity, velocity = unit(target - pos) * GRAPPLE_SPEED (22.0) and
     normal collision; the grapple ends when within 1.0 of the target, when the frames run out, or when BTN_JUMP is
     pressed (rising edge; this also performs a normal jump if one is available). Cooldown = tuned dash cooldown,
     started when the grapple fires. No dash.
   - Ground acceleration and braking are multiplied by `tuning.friction_mul`, clamped to
     [FRICTION_MUL_MIN = 0.1, TUNING_MUL_MAX]; NaN means 1.0 (like the existing NaN handling). Air control is not
     affected. Add the new constants to `tuning.rs`.
3. `sim-wasm/src/lib.rs`: add `vw_set_tiles(len: u32) -> i32` that decodes a bincode `Vec<TileState>` from the shared
   IO buffer exactly like the other `vw_set_*` functions decode their input, applies it to the loaded world, and
   returns 0 on success and a negative value on a decode error. Extend the bridge test.
4. Tests (in the files above): each class ability, glide fall cap, blink stopped by a wall, blink with no direction,
   grapple picks the expected platform and ends near it, grapple cancelled by jump, ice (friction 0.25) takes longer
   to stop than normal, NaN friction behaves as 1.0, the striker is unchanged.
