## What changed (facts)
Download and start (Windows):
- The Windows download (`VOIDWRAP_RUN-<version>-windows.zip`) now contains: `VOIDWRAP RUN.exe` (the game),
  `PLAY-IN-BROWSER.cmd`, a `web` folder, and this guide. There is no PLAY.cmd / PLAY-WITH-FRIENDS.cmd any more.
- Extract the zip first (same steps as before). Then double-click `VOIDWRAP RUN` (it may show as `VOIDWRAP RUN.exe`).
  The game opens in its OWN WINDOW (not in the browser). There is no black window any more. Close the game window to
  stop the game.
- The blue "Windows protected your PC" box may still appear the first time: More info -> Run anyway. Smart App
  Control note stays as before.
- The first time you turn on "Let friends join", Windows may ask "Allow access?" - click Allow access.
- If the game window stays empty/white or does not open: double-click `PLAY-IN-BROWSER` instead. A black window opens
  and the game opens in the web browser (keep the black window open; close it to stop). If the browser does not open
  by itself, type `localhost:7878` in the address bar.
- If something goes wrong, the game writes a file `voidwrap.log` in the same folder - attach it to a bug report.
- Linux: unchanged (`./play.sh`), it plays in the browser.

Title screen: three buttons - PLAY (play alone, or with friends who already joined), PLAY WITH FRIENDS, JOIN A FRIEND.

Playing with friends (the host's computer runs the game; friends need nothing installed except a web browser, OR
the game itself if they want the game window):
- Host: click PLAY WITH FRIENDS, switch on "Let friends join". The panel shows:
  "FRIENDS ON YOUR WI-FI": an address like `http://192.168.1.23:7879` with a Copy button - for friends on the same
  Wi-Fi/network.
  "FRIENDS ANYWHERE": an address like `http://203.0.113.5:7879` - only shown when the game managed to set up your
  router automatically (this is called UPnP). Send it to friends who are somewhere else.
  If the panel says "Your router did not allow automatic setup", friends on your Wi-Fi can still join. For friends
  elsewhere you must either turn on "UPnP" in your router's settings (ask whoever manages your internet; every
  router is different) or "forward" port 7879 (TCP) to your computer in the router settings, then send them your
  public address. Only share the address with people you trust; switch "Let friends join" off when you are done.
- Then click START PLAYING.
- Friend: open the address the host sent in any web browser (copy it into the address bar, press Enter) - OR, if
  they have the game, click JOIN A FRIEND, paste the address, click Join. Up to 8 players.
- Everyone votes on the cards; the level starts when everybody pressed Continue. Spectator rules as before.

How a run works (changes):
1. Level 1 is a clean start: no hunters, no upgrades, no curses. On this screen each player CHOOSES A CLASS (keys 1-4
   or click), then CONTINUE. The class stays for the whole run.
   Classes (ability on Shift or right mouse button):
   - Striker: dash, a short burst forward.
   - Grappler: fires an auto-aimed grapple that pulls you to the platform ahead (move toward it while pressing).
   - Blinker: instantly teleports up to 6 units toward where you move; walls stop you.
   - Glider: one extra jump in mid-air; hold Shift while falling to glide slowly.
2. From level 2 on, the lobby shows the cards (2 hunters on the first card lobby, then 1 reward card each time) AND
   a LOBBY SHOP below them (scroll down): items cost gold from golden gifts (the money is shared by the team). Each
   item shows its price and how many are left; the Buy button explains when you cannot afford it. Items: an extra
   life, a "reroll" that swaps the reward cards, and small permanent boosts.
3. Levels can have an EVENT, announced at the start: High Rise (platforms climb higher), Slick Ice (you slide and stop
   slowly), Crumbling (cracked platforms fall away a moment after you step on them and come back after 3 seconds).
4. Some levels have an ALTAR (a small stone shrine with a glowing sign). Walk up to it and press E: you get one random
   upgrade AND one random curse. Each altar works once.
5. New hunters: Bolt Sentry (never moves, shoots slow glowing bolts - hide behind platforms), False Gift (looks
   exactly like a gift until you come close, then chases you), Crumble Wisp (slow, makes platforms near it crumble).
   Hunters are harmless for their first few seconds; a bolt hit counts as being caught.
6. Controls table additions: E = use an altar; 1-4 = choose class (first lobby); Shift / right mouse = class ability.
