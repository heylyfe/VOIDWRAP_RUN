# Ticket T-011: M1 HUD components (gifts, level, level banner, run summary)
Target: GLM

## Context
Next.js 16 (App Router) + React 19 + TypeScript 6 strict (`noUncheckedIndexedAccess` on) + Tailwind CSS v4
(utility classes only; arbitrary values like `bg-[#07060d]` are fine). Path alias `@/` → `web/src/`.
These components render as a DOM overlay above a full-screen WebGL canvas, inside a parent that is
`position: relative; width: 100vw; height: 100vh`. They are purely presentational: props in, markup out —
no data fetching, no global state, no timers except where stated.

Palette (use only these colours, plus white/black with opacity):
- void `#07060d`, panel `#120f1f`
- magenta (primary accent) `#ff3db8`
- cyan (secondary accent) `#38e8ff`
- gift gold `#ffd23d`
- danger `#ff4d4d`
Font: monospace (`font-mono`). Text must stay readable over a busy, colourful 3D scene: panels use
`bg-black/60` or the panel colour, and key numbers are large and bold.

Existing conventions: overlays use `pointer-events-none` except interactive elements; tests use
`data-testid` attributes (the automated screenshot tool looks them up).

## Task
Create `web/src/hud/` with:

1. `web/src/hud/format.ts` — pure helpers:
   - `export type DeathCause = "void" | "enemy" | "disconnect";`
   - `export function causeText(cause: DeathCause): string` → `"Fell into the void"`, `"Caught by an enemy"`, `"Lost connection"`.
   - `export function giftsLabel(remaining: number, total: number): string` → e.g. `"3 / 5"`; clamps `remaining` into `[0, total]` and treats negative/NaN `total` as 0.
2. `web/src/hud/GameHud.tsx` — `export function GameHud(props: { level: number; giftsRemaining: number; giftsTotal: number }): JSX.Element`
   Top-centre panel: "LEVEL {n}" and a gift counter showing a small gold square icon + `giftsLabel(...)` (`data-testid="gifts-remaining"`, `data-testid="level-number"` on the number). When `giftsRemaining === 0` and total > 0, show "BEACON OPEN" in cyan under the counter (`data-testid="beacon-open"`).
3. `web/src/hud/LevelBanner.tsx` — `export function LevelBanner(props: { level: number }): JSX.Element | null`
   Large centred "LEVEL {n}" title that appears whenever `level` changes and fades out after ~1.5 s
   (use `useEffect` + `setTimeout`, clean up the timer; render `null` when hidden). `data-testid="level-banner"`.
4. `web/src/hud/RunSummary.tsx` — `export function RunSummary(props: { levelReached: number; giftsCollected: number; cause: DeathCause; onRestart: () => void }): JSX.Element`
   Full-screen modal over a `bg-black/70` backdrop (`data-testid="run-summary"`): heading "RUN OVER" in magenta,
   rows for "Level reached", "Gifts collected", "Cause" (`causeText`), a primary button "Run again"
   (`data-testid="run-again"`, calls `onRestart`, autofocused, also triggered by pressing Enter while the
   summary is shown — add/remove a window keydown listener in `useEffect`), and a secondary link
   "Back to title" to `/` (use `next/link`). This element must have `pointer-events-auto`.
5. `web/src/hud/format.test.ts` — vitest tests for `causeText` and `giftsLabel` (`import { describe, expect, it } from "vitest";`).

## Constraints
- Create only the five files above. Do not modify any other file.
- Function components with explicit prop types; named exports only; no `any`; no non-null assertions (`!`)
  outside tests; no default exports.
- Import React types as `import type { JSX } from "react";` where you need `JSX.Element`.
- No new dependencies. No inline `<style>` tags, no CSS files.
- Accessible: buttons are real `<button type="button">`, the modal has `role="dialog"` and `aria-modal="true"` and an `aria-labelledby` pointing at its heading.

## Acceptance criteria
- [ ] `giftsLabel(3, 5) === "3 / 5"`, `giftsLabel(9, 5) === "5 / 5"`, `giftsLabel(-2, 5) === "0 / 5"`, `giftsLabel(1, NaN) === "0 / 0"` — tested.
- [ ] `causeText` returns the three exact strings — tested.
- [ ] All data-testids listed above present.
- [ ] Enter key and button both call `onRestart`; listener removed on unmount.
- [ ] LevelBanner clears its timer on unmount / level change.
- [ ] `tsc --noEmit`, `eslint .` (typescript-eslint strict + react-hooks recommended) and `vitest run` pass.

Verification commands (run by OVERSEER): `pnpm --dir web exec tsc --noEmit`, `pnpm --dir web exec eslint .`, `pnpm --dir web exec vitest run`.
