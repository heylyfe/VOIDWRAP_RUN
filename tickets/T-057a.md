## Task
1. `web/src/scene/enemies/`: one component per enemy (`Pallbearer.tsx`, `Snapshrike.tsx`, `Moteling.tsx`,
   `RiftWarden.tsx`, `GaleWight.tsx`, `LanternLeech.tsx`, `BoltSentry.tsx`, `FalseGift.tsx`, `CrumbleWisp.tsx`) built
   from three.js primitives per the VISUAL briefs: strong silhouettes, emissive accents in the listed colours, idle
   and attack animation (driven by a `stateRef`/`progRef` the parent updates - no React re-render per frame),
   readable in fog (emissive parts + a small point light only where the brief says; keep total lights <= 1 per
   enemy). Unit-radius models (the parent scales by the body radius). DORMANT = dimmed + slow idle. The False Gift
   while DISGUISED must look exactly like a normal gift (the gift is small now: 0.34 u, use GiftBox at that size,
   never scaled by the radius) except its periodic 0.5 s shimmer.
2. `web/src/scene/Telegraphs.tsx`: pooled telegraph drawings per the design: ground rings (circle at target,
   tightening by prog for moteling/gale_wight), lines (snapshrike lock line enemy->target, pallbearer kneel line,
   turret aim line), lantern_leech destination flare + path, rift_warden shove radius ring, mimic hiss glitch. All
   bright, additive, in the enemy's accent colour, alpha/scale from prog; nothing when state is not
   TELEGRAPH/ATTACK.
3. Rewrite `EnemyField.tsx` to pool slots (max 24) that each pre-build all nine models and switch visibility by
   kind, plus the telegraph pool; gale_wight shells use `Projectiles.tsx` (a falling glowing shell with a streak).
4. Remove `Chaser.tsx`, `Turret.tsx`, `Mimic.tsx`, `Corrupter.tsx` (output them as empty? NO - just stop importing
   them; list them in NOTES so the lead deletes them). Keep `EnemyField`'s props the same so GameClient needs no
   change (if a prop must change, say so in NOTES).
5. Pure helpers (`enemyLook.ts`: kind -> accent colours, behaviour id; telegraph alpha/scale curves) with tests.
