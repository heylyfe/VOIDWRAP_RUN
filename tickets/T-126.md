# T-126 — `8.hazard_entities` was too weak to catch what it was built for

**Cycle 12, refinement 3 of 3.** T-125 fixed two patterns whose
`hazard:trampoline` tag was a lie. This fixes the metric that let them through.

## The defect

```js
if (tagged.length > 0 && withEntity.length === 0) allOk = false;
```

The metric only failed when **no** tagged pattern carried the entity. Three
patterns tagged, one carrying, passed. That is exactly the state
`hazard:trampoline` was in for an unknown number of releases:

```
hazard:trampoline: 3 patterns tagged, 1 carry a TRAMPOLINE platform (33.3%)
```

A metric whose own closing line reads "a tag with no entity is a promise the
engine does not keep" should not accept a 33 % keep rate.

## Change

1. **Every tagged pattern must carry the entity**, not just one of them. The
   failure line now names the offenders, so the next occurrence is a fix rather
   than an investigation.
2. **`hazard:crumble` is checked too.** It was never in the list, so the same
   class of defect could have been sitting in the most common hazard in the
   catalog (42.6 % of hazard-tagged placements) with nothing watching.
3. **`hazard:fog` is documented as deliberately absent.** It is an atmospheric
   event with no platform kind; adding it would make the metric fail forever.

## Measured after

```
PASS — 8.hazard_entities
       hazard:crumble: 7 patterns tagged, 7 carry a CRUMBLE platform (100.0%)
       hazard:trampoline: 3 patterns tagged, 3 carry a TRAMPOLINE platform (100.0%)
       hazard:tripmine: 4 patterns tagged, 4 carry a TRIPMINE platform (100.0%)
       a tag with no entity is a promise the engine does not keep
```

Economy audit **9/9**, pattern audit **16/16**, `just verify` green.

## Tuning notes

- `hazard:crumble` is 7 patterns and 42.6 % of hazard-tagged placements — by far
  the most common hazard. It was the one with no entity check.
- The three platform-backed hazards are now all at 100 %. The remaining
  thinness is coverage, not correctness: trampoline 3/135, tripmine 4/135,
  crumble 7/135.
- This is the second metric this cycle whose threshold was looser than its
  stated intent. Worth a pass over the other `metric(...)` calls in the economy
  audit for the same shape of bug.
