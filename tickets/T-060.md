Facts for alpha 3 (on top of alpha 2):
- Windows downloads: an INSTALLER `VOIDWRAP_RUN-<version>-windows-setup.exe` (recommended: double-click, the blue
  "Windows protected your PC" box -> More info -> Run anyway, then Next/Install; it needs no administrator rights;
  installs for the current user; Start menu + optional desktop shortcut "VOIDWRAP RUN"; "Start VOIDWRAP RUN now" at
  the end; uninstall via Windows Settings > Apps or the Start menu) OR the zip as before. The game has its own icon.
- Mouse: Ctrl locks/unlocks the mouse (shown at the bottom of the screen); clicking the game also locks it.
- Maps are now huge and built from hand-made pieces: stacked layers on pillars, stairs you can walk up without
  jumping (small steps), towers, two-level bridges, jump pads (glowing pads that launch you about 4 m up), loops and
  junctions. Every map is checked so every gift and the beacon can be reached.
- Two-phase levels: ~50 small gifts on level 1 (more each level, up to 400). Collect them all -> a 3 s warning ->
  the map COLLAPSES from the outside in (tiles shake and flash before they fall), every collected gift's spot becomes
  a GOLDEN gift (1 gold each, shared team money), the beacon on the spawn platform lights up - walk into it to finish.
  Golden gifts on fallen tiles are lost. The spawn platform never falls.
- Classes: Striker (dash), Grappler (grapple), Glider (extra jump + glide), and the new BULWARK (replaces the old
  Blinker): on the ground, press Shift/right mouse to root yourself for 1.6 s and push everything nearby away;
  nothing can hurt you then except falling shells; long cooldown (16 s).
- All nine hunters reworked - each tests a different skill, every deadly attack is announced by a visible warning
  (ring, line, flare) 0.6-2.5 s before it lands; some hunters push or slow you instead of killing. Full guide in
  ENEMIES.md (included in the download and the Start menu folder is not needed - say "in the game folder").
- Shop prices doubled because you earn far more gold now.
- Milestones: from level 4 on, some levels announce a change (more hunters, shorter tile warnings, thicker fog).
