# Ticket T-014: M1 visual QA review
Target: INKLING-VISION

## Context
Five screenshots (1280×720) from a fast-paced 3D platformer prototype, in this order:
1. `00-title.png` — title screen
2. `01-spawn.png` — player (blocky figure, magenta shirt) at the start of level 1. Gold boxes with magenta ribbons are
   collectible gifts; the red spiky octahedron is an enemy that chases the player; the tall dim translucent pillar
   is the exit beacon (it lights up cyan once all gifts are collected). Top centre: level number and gifts remaining.
3. `02-moving.png` — the player has just run off a platform edge and is falling into the void.
4. `05-run-summary.png` — the death screen.
5. `06-new-run.png` — right after pressing "Run again".

Intended look: maximalist, chromatic, slightly chaotic colour against a dark void, with high-contrast silhouettes that
stay readable at speed. Palette: void #07060d; platform families #3b2a6b, #1f4b7a, #5a1f5e, #20565a; accents cyan
#38e8ff and magenta #ff3db8; gift gold #ffd23d; enemy red #ff4d4d. No post-processing (glow/bloom, chromatic
aberration) has been added yet — that is planned later; do not list its absence as a finding.

## Task
Review ONLY what is visible. For each finding give: screenshot number, what you see, why it hurts readability /
game feel / the intended look, and a concrete fix (what to change, e.g. colour, size, position, intensity).
Rank findings by severity (high / medium / low). Maximum 10 findings. Then list up to 3 things that already work
well (so they are kept). Do not speculate about code or about anything not visible; if unsure, say so.

## Constraints
NOTES block only (no FILE blocks). Be specific and terse.
