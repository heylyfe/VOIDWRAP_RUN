# Ticket T-077: uniqueness and pattern audit (black-box)

Prove the pattern engine delivers what the owner asked for: every level feels unique. Measure, do not
judge.

## The audit

`tools/pattern-audit/run.mjs`, Node built-ins only, no new dependencies. It runs the generator over
5,000 seeds and prints `PASS/FAIL - <metric>` per metric with the raw numbers.

## Metrics

1. **Pattern repeat rate**: how often the same pattern appears twice in one level, and how often the
   same ordered pattern list appears across seeds. The second must be effectively zero.
2. **Tag diversity**: distinct theme tags per level, distinct mechanic tags per level, and the
   distribution across the whole run.
3. **Anchor failures**: how many seeds fail to stitch and fall back, and why.
4. **Near-duplicate flagging**: levels whose pattern sets overlap above a threshold you justify.
5. **Heights and ramps**: verify every generated level against the T-068 ramp rules (rise over run at
   most 0.5, no stair sequences) and the reference scale (platforms 10-20 u, height differences 1-6 u).
6. **Enemy spawn frequencies**: per level and per mode, are any enemies never offered or always
   offered?

## Output

- `PASS/FAIL - <metric>` lines with the measured value and the threshold you chose.
- A table of flagged outliers with concrete numbers (seed, level, what was wrong).
- Exit 0 only when every metric is inside its threshold.

## Output format

Complete files with `=== FILE: <path> ===` ... `=== END FILE ===`. Allowed paths: anything under
`tools/pattern-audit/`.

Do not touch `server/`, `web/`, or `design/`. No new dependencies.

## Done when

The audit runs over 5,000 seeds, prints concrete numbers, and `just verify` stays green with the audit
skipped by default (env-gated). Put the full numbers in NOTES.
