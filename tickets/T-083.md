# Ticket T-083: risk/reward altars

Mid-level, one-time altars with a real cost. At least four designs. Optional, single-use, and their
effects serialize into run state so they survive level transitions.

## What exists (verified)

- `LevelData` already carries `altars: Vec<Altar>` and the snapshot carries `altars_used`, so the
  placement and the used-flag plumbing exist.
- `server/crates/server/src/run.rs` owns run state; `design/content.json` has an `altars` section.
- The controller already handles `BTN_INTERACT` on a rising edge for altar use.

## The four designs (implement all four)

1. **Shortcut**: skip straight to the next shop on level completion, at the cost of two temporary
   curses and more enemies next level.
2. **Gift sight**: every gift is highlighted for this level, but the next pedestal options come from
   the hardest pool.
3. **Clear sky**: this level's fog is cleared, but Lure and Static spawn immediately.
4. **Debt**: take a large currency advance now, repay it from the next two levels' income.

## Requirements

- Each altar is single-use per level and its effect is applied exactly once.
- Costs are real and visible before the player commits (the client must be able to show them).
- Effects serialize into run state: a test must prove an altar's effect survives a level transition
  and a server restart of the run state (serialize, deserialize, still applied).
- Tests per altar: the benefit applies, the cost applies, and using it twice does nothing the second
  time.
- Doc-comment every public item.

## Output format

Complete files with `=== FILE: <path> ===` ... `=== END FILE ===`, or single functions with
`=== FN: <path> :: <name> ===` ... `=== END FN ===`. Allowed paths: `server/crates/server/src/`,
`server/crates/sim/src/`, `design/content.json`.

Do not touch `web/` or `protocol/` unless a client-visible field is genuinely required; if it is,
change `protocol/schema.json` and note that the lead must run `just gen` and `just fixtures`.

## Done when

`cargo test -p server` passes with the new tests and clippy is clean. Put the numbers you chose in
NOTES.
