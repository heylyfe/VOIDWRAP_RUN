# Ticket T-084: greater curses + the stair-reference audit

A tier above normal curses: run-shaping threats with escape mechanics. Three of them, anchored by
Wreath. They enter through pedestal voting and are clearly marked as greater.

## What exists (verified against the tree)

- `design/content.json` has 14 curses, 3 already `greater: true` (`the_hollow_choir`, `leaden_sky`,
  `world_of_teeth`) - all pure stat mods, no mechanics. The validator already requires >= 3 greater
  curses, so adding more is safe.
- `ModCard` (`server/crates/server/src/content.rs:141`) is `{id, mods: BTreeMap<String,f32>, greater}`.
  `mods` may be `{}`. **Do not change `ModCard`** - the mechanic is derived from the curse id.
- `PlayerSense` (`server/crates/sim/src/hazards.rs:171`) already carries `jump_launched` and `gliding` -
  exactly Wreath's two escapes. **Do not add fields to it.**
- T-068 removed stairs; ramps replaced them everywhere.

## Part 1 - `server/crates/sim/src/greater.rs` (new file, complete)

Pure logic. No server deps, no wall clock, no transcendentals (see the crate header in `lib.rs`).
Must compile for `wasm32-unknown-unknown`. Doc-comment every public item.

```rust
//! Greater curses (T-084): run-shaping threats with escape mechanics.

/// Ticks a Wreath cries before its victim dies (12.0 s at 20 Hz).
pub const WREATH_CRY_TICKS: u32 = 240;
/// Ticks of visible crying before the timer starts biting (3.0 s).
pub const WREATH_GRACE_TICKS: u32 = 60;
/// Currency Tithe takes per normal gift collected.
pub const TITHE_PER_GIFT: u32 = 1;
/// Ticks of slow a Tithe victim carries after collecting at zero currency (6.0 s).
pub const TITHE_SLOW_TICKS: u32 = 120;
/// Speed multiplier while a Tithe victim is slowed.
pub const TITHE_SLOW_MUL: f32 = 0.75;
/// Fog multiplier Hush applies on top of the run's other fog mods.
pub const HUSH_FOG_MUL: f32 = 1.6;

/// The three greater curses that carry a runtime mechanic.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum GreaterCurse { Wreath, Tithe, Hush }

impl GreaterCurse {
    /// Every mechanic-bearing greater curse, in content order.
    pub fn all() -> [GreaterCurse; 3];
    /// Map a `design/content.json` curse id to its mechanic; `None` for stat-only curses.
    pub fn from_id(id: &str) -> Option<GreaterCurse>;
    /// The content id this mechanic is driven by.
    pub fn id(self) -> &'static str;
}

/// One Wreath attached to one player.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct Wreath { /* victim: u32, ticks: u32 */ }

/// What one Wreath tick did.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum WreathOutcome { Escaped, Crying, Killed }

impl Wreath {
    /// Attach a fresh Wreath to `victim`.
    pub fn attach(victim: u32) -> Wreath;
    /// The player it sits on.
    pub fn victim(&self) -> u32;
    /// Ticks it has cried so far.
    pub fn ticks(&self) -> u32;
    /// True once the grace window is over and the timer is biting (drives the loud telegraph).
    pub fn is_biting(&self) -> bool;
    /// Advance one tick. `escaped` is true when the victim launched off a jump pad or is gliding
    /// this tick - the level's own geometry is the counter. Escaping ends the Wreath.
    pub fn tick(&mut self, escaped: bool) -> WreathOutcome;
}

/// Per-player Tithe slow timer.
#[derive(Debug, Clone, Copy, PartialEq, Eq, Default)]
pub struct TitheSlow { /* ticks: u32 */ }

impl TitheSlow {
    /// Start (or refresh) the slow.
    pub fn apply(&mut self);
    /// Advance one tick.
    pub fn tick(&mut self);
    /// True while the player is slowed.
    pub fn is_slowed(&self) -> bool;
    /// `TITHE_SLOW_MUL` while slowed, else `1.0`.
    pub fn speed_mul(&self) -> f32;
}

/// Currency Tithe takes for `gifts` normal gifts collected.
pub fn tithe_cost(gifts: u32) -> u32;
```

`Wreath::tick` semantics, exactly:
- `escaped == true` -> return `WreathOutcome::Escaped` and leave `ticks` unchanged.
- otherwise `ticks += 1`; return `Killed` when `ticks >= WREATH_CRY_TICKS`, else `Crying`.
- `is_biting()` is `ticks > WREATH_GRACE_TICKS`.

Tests (in the same file, `#[cfg(test)] mod tests`): escape by jump pad, escape by glider, kill at
exactly `WREATH_CRY_TICKS`, still crying one tick before that, quiet during grace, `tithe_cost`
saturates, `TitheSlow` applies/expires/`speed_mul`, `from_id` round-trips `all()` and rejects
`"leaden_sky"`.

### 2b. Replace `collect_gifts` - Tithe takes currency per normal gift

Current body (verbatim, so you can reproduce it with the Tithe hook added):

```rust
    pub fn collect_gifts(&mut self, feet: &Vec3) -> Vec<Vec3> {
        let mut picked = Vec::new();
        if self.phase != PHASE_PLAYING {
            return picked;
        }
        let radius = GIFT_RADIUS * self.mods.gift_radius_mul;
        if self.level_phase == LEVEL_COLLECT {
            for gift in &self.level.gifts {
                if self.gifts_taken.contains(&gift.id) {
                    continue;
                }
                if rules::gift_touched_within(feet, gift, radius) {
                    self.gifts_taken.push(gift.id);
                    self.gifts_collected = self.gifts_collected.saturating_add(1);
                    picked.push(gift.pos);
                }
            }
            // The last gift (including the vacuous zero-gift case) starts phase 2.
            if self.normal_left() == 0 {
                self.enter_collapse_pending();
            }
            return picked;
        }
        // Phase 2: one golden gift per collected normal gift, at its exact position. The ids are
        // gathered first so the loop only holds an immutable borrow of `self.level.gifts`.
        let mut golden: Vec<u16> = Vec::new();
        for gift in &self.level.gifts {
            if !self.gifts_taken.contains(&gift.id) {
                continue;
            }
            if self.golden_taken.contains(&gift.id) {
                continue;
            }
            if self.platform_gone_for_gift(gift.id) {
                // The tile fell: the uncollected golden gift vanished forever.
                continue;
            }
            if rules::gift_touched_within(feet, gift, radius) {
                golden.push(gift.id);
                picked.push(gift.pos);
            }
        }
        for id in golden {
            self.golden_taken.push(id);
            self.credit_income(GOLDEN_VALUE);
        }
        picked
    }
```

The Tithe hook goes in the `LEVEL_COLLECT` branch only (golden gifts are income, not tithed).
After `self.gifts_collected = ...`, add exactly:

```rust
                    if self.curses.iter().any(|c| c == "tithe") {
                        self.currency = self.currency.saturating_sub(sim::greater::TITHE_PER_GIFT);
                    }
```

Keep the borrow structure identical. The loop reads `self.level.gifts` while mutating
`self.gifts_taken` / `self.gifts_collected` / `self.currency`; those are disjoint fields so this
compiles. If it does not, collect the touched gift ids first and apply the mutations after the loop,
exactly like the golden branch already does.
