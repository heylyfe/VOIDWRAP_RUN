# T-148 — `6.enemy-frequencies.always-offered` compared placements to levels

**Cycle:** 21
**Status:** PASS
**Area:** `tools/pattern-audit/run.mjs`

## What was wrong

The check is meant to catch a `(mode, level)` cell where one enemy type is offered in
**100% of levels** — the strongest possible form of "this cell never varies". It read:

```js
for (const [t, c] of cell.byType) {
  if (c === cell.levels) { alwaysCells.push(...); }
}
```

`cell.byType` counts **placements**. `cell.levels` counts **levels**. A level carries
several spawn markers, so placements always exceed levels and the equality can only hold
if every level in the cell has exactly one enemy — which never happens.

Measured on the 400-seed dump:

```
1|1  type=spawn  placements=3200  cellLevels=400  c===levels? false
4|1  type=spawn  placements=3200  cellLevels=400  c===levels? false
8|1  type=spawn  placements=3200  cellLevels=400  c===levels? false
```

3200 against 400. The check reported **PASS on every run since it was written** while
being structurally incapable of failing. This is the same defect class T-144 fixed
elsewhere in this file (a metric that cannot fail), in a check T-144 itself touched: T-144
removed the `cell.byType.size >= 2` filter that was hiding the single-type case, but left
the units mismatch underneath it, so removing the filter changed nothing.

## The fix

1. **Track levels, not placements.** `consumeRecord` now also fills
   `cell.levelsWithType: Map<type, number>` — the count of levels in the cell containing
   that type at least once, deduped per record. `byType` keeps its placement counts for
   the distribution printout.
2. **Compare like with like.** The check iterates `cell.levelsWithType` and compares
   against `cell.levels`.
3. **An empty denominator is a SKIP, not a PASS.** If no cell reaches the minimum level
   count, the loop never runs and the metric would report PASS having examined zero cells.
   It now says so, naming the largest cell it saw.
4. **The generic marker is not an enemy type.** The dump's `enemies` array carries
   `{"type":"spawn"}` markers, not roster ids — the type is chosen at runtime from the
   pedestal pool. A marker present in every level *by construction* would make the fixed
   check fire on every run for a reason that is not a defect. When every placement is the
   generic marker, the metric SKIPs and points at the check that can answer it
   (`economy-audit 3.pedestal_pool`, which reads the registry directly).
5. **The threshold is injectable** (`ctx.enemyAlwaysCellMin`) so `--selftest` can exercise
   the check with its 3-level synthetic cells instead of being filtered out by the real
   threshold of 20.

## Negative test

`--selftest`'s synthetic records carry the same two enemy types in every record — a
planted zero-variety defect. With `enemyAlwaysCellMin: 3` the check now reaches them:

```
[selftest] FAIL - 6.enemy-frequencies.always-offered ((mode, level) cells with >= 3 levels
           where a type appears in 100% of levels: 4 across 2 cells; threshold: 0)
```

`6.enemy-frequencies.always-offered` is now in the selftest's `expected` set, so
`just verify` fails if the check ever stops firing on the planted defect.

## Choice log

- **Fixed the units rather than deleting the check.** The check is correct in intent; only
  its arithmetic was wrong. Deleting it would have removed the guard for the day the dump
  does carry enemy types.
- **SKIP rather than invent data.** The alternative was to make the dump emit real enemy
  types. That needs the pedestal-pool logic, which lives in the `server` crate
  (`run.rs::vote_pool_with`), while the dump lives in `sim`
  (`crates/sim/examples/pattern_dump.rs`). Moving it is a crate-boundary decision, not a
  polish diff. Logged as a Cycle 22 candidate instead.
- **Kept `byType`.** The distribution printout and `distinct` in the failure detail still
  want placement counts. Two maps, two meanings, both named for what they hold.
- **Did not lower the real threshold.** 20 levels is the right bar for a 400-seed dump;
  lowering it to make the selftest pass would have been the tail wagging the dog. The
  threshold is injectable instead.
