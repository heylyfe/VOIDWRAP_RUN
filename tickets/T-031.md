### What it is
VOIDWRAP RUN is a fast 3D platformer that runs in your web browser. It is a pre-release ALPHA: things will change and
there may be bugs. Official tagline: `Collect every gift. Outrun what you voted for.`

### Downloading (Windows)
- Releases page: https://github.com/heylyfe/VOIDWRAP_RUN/releases
- The newest version is at the top (labelled "Pre-release"). Under "Assets", click the file whose name ends in
  `-windows.zip` (e.g. `VOIDWRAP_RUN-v0.1.0-alpha.1-windows.zip`). It is about 2-3 MB.
- The browser saves it to the Downloads folder.
- IMPORTANT: unzip it first. Open the Downloads folder, RIGHT-click the zip file, choose "Extract All...", then click
  "Extract". A normal folder named `VOIDWRAP_RUN-...` opens (inside it there is a folder `VOIDWRAP_RUN`). Running the
  game from inside the zip without extracting does not work.
- Inside the `VOIDWRAP_RUN` folder there are: `PLAY.cmd`, `PLAY-WITH-FRIENDS.cmd`, `voidwrap-server.exe`, a `web`
  folder, and this guide. Do not move files out of this folder or delete the `web` folder.
- Windows may hide the ".cmd" ending, so the files may just show as "PLAY" and "PLAY-WITH-FRIENDS".

### Starting the game (Windows)
- Double-click `PLAY` (PLAY.cmd).
- The FIRST time, Windows may show a blue box "Windows protected your PC". This appears for new games from small
  developers that are not "signed" (a paid certificate). Click "More info", then click "Run anyway".
- On some Windows 11 computers "Smart App Control" blocks the game completely with no "Run anyway" button. In that case
  the game cannot run on that PC right now (turning Smart App Control off is possible in Windows Security, but it cannot
  be turned back on without resetting Windows - only do that if you understand it).
- A black window (the "console") opens with some text. KEEP IT OPEN while you play. Closing it stops the game.
- Your web browser opens the game by itself after a moment. If it does not, open your browser (Chrome, Edge or Firefox)
  and type `localhost:7878` into the address bar at the top, then press Enter.
- To stop playing: close the browser tab, then close the black window.

### Linux
Download the file ending in `-linux.tar.gz`, extract it, open a terminal in the `VOIDWRAP_RUN` folder and run
`./play.sh` (or `./play.sh friends` to host for friends).

### Playing (controls)
- Click once inside the game so it can use your mouse (the mouse pointer disappears). Press Esc to get the pointer back.
- Move: W A S D (or the arrow keys). Look around: move the mouse.
- Jump: Space (hold it for a higher jump, tap for a small hop).
- Dash (a quick burst forward): Shift or the right mouse button.
- Number keys 1-9 and Enter work on the selection screen.

### How a run works
1. You start in the LOBBY, standing on a big checkered platform. A screen with cards appears.
2. "WHO HUNTS YOU - choose 2": pick 2 enemy cards. Each card explains how that enemy moves and how dangerous it is
   (red dots = threat). These enemies will chase you during the run.
3. "TAKE ONE FROM THE VOID - choose 1": pick 1 card. Blue cards (UPGRADE) help you. Red cards (CURSE) make the run harder.
4. Click a card to choose it (click again to un-choose). Then click CONTINUE (or press Enter).
5. A new, randomly made level appears. Everyone starts on the big platform.
6. Collect the 5 gold gifts with the pink ribbons (the counter at the bottom shows how many you have, e.g. 2 / 5).
   Touching a gift collects it.
7. When all 5 are collected, golden bonus gifts appear (they are money for later) and the exit (a tall pillar of light,
   the "beacon") turns on. Walk into the light to finish the level.
8. You go back to the lobby, pick a new card, and the next level starts. The enemies stay the same for the whole run.
9. If you fall off into the void or an enemy touches you, the run ends (unless you picked an extra life). Press
   "Run again" to start a new run.
- Enemies are asleep for the first few seconds of a level - use that time.
- The top-right box shows your money, lives, your enemies and your cards. Point at a name to see what it does.

### Playing with friends (same home network)
- One person (the "host") double-clicks `PLAY-WITH-FRIENDS` instead of `PLAY`.
- Windows may ask "Allow access?" (Windows Defender Firewall). Click "Allow access" - otherwise friends cannot join.
- The black window shows one or more addresses like `http://192.168.1.23:7878`.
- Friends on the SAME Wi-Fi/network type that address into their browser's address bar (they do NOT need to download
  anything).
- Up to 8 players. Everyone votes on the cards; the level starts when everybody has pressed Continue.
- When you reach the beacon (or run out of lives) you become an invisible SPECTATOR until the others finish: fly with
  W A S D, Space up, C down, Shift faster; press F to follow another player, G to fly freely again.
- Playing with friends over the internet (not on your network) is not supported in this alpha yet.

### Something went wrong?
- "Windows protected your PC": More info -> Run anyway (see above).
- The black window opens and closes immediately: you are probably running it from inside the zip - extract first.
- The browser shows "This site can't be reached": the black window is closed or still starting - wait a few seconds,
  make sure the black window is open, then refresh the page (F5).
- The black window says the address is already in use: the game is already running in another black window - close
  the extra one, or restart the computer.
- The game is black/very slow: update your browser; use Chrome or Edge; close other heavy programs. The bottom-left
  corner shows "fps" (frames per second) - 60 is smooth.
- Friends cannot join: they must be on the same Wi-Fi, you must have clicked "Allow access", use the address shown
  in YOUR black window (not localhost), and your antivirus/firewall may need to allow `voidwrap-server.exe`.
- Report bugs: https://github.com/heylyfe/VOIDWRAP_RUN/issues ("New issue", describe what happened).

### For developers (building from the source code)
Prerequisites: Rust (stable, from rustup.rs), Node.js 24+, pnpm (`npm install -g pnpm`). Then in the project folder:
`rustup target add wasm32-unknown-unknown`, `pnpm install`, `npm start` (builds everything and opens the game).
`npm run start:friends` hosts for your network. Development with hot reload: `npm run dev`.
Optional: the `just` tool for `just verify` (all checks).

### Hosting online for free (advanced)
The repository includes a `Dockerfile` and `render.yaml` for Render.com's free plan: sign in to Render with GitHub,
"New" -> "Blueprint", choose the repository. The free plan sleeps after ~15 minutes without visitors; the first visit
then takes about a minute to wake up.
