Official copy — must be used VERBATIM (exact wording, punctuation, capitalisation):

- Short description: `VOIDWRAP RUN is a fast-paced 3D roguelite collectathon platformer. Collect all the gifts across endlessly generated void worlds, survive the enemies and curses you drafted yourself, and see how deep one run can go.`
- Long description: `Every run drops you into a freshly generated sprawl of floating platforms hanging in a dark, chromatic void. The job is simple: collect every gift, reach the beacon, go deeper. The problem: at the start of each run you vote on which enemies hunt you, and every level you clear hands you a new curse to make it hurt. Pick a class, chain upgrades, gamble at altars, dress up your blocky little guy — and find out how deep one run can go. Play solo, or drag up to 7 friends into the void with you.`

Current state of the software (milestone M0 — bootstrap): a grey platform floating in the void with a controllable blocky player; an authoritative game server ticking at 20 Hz; client-side prediction. Gifts, enemies, curses, classes, multiplayer lobbies are NOT built yet — they are on the roadmap.

Tech: Rust authoritative server (tokio + axum WebSockets, bincode protocol) in `server/`; Next.js + TypeScript + react-three-fiber client in `web/`; the movement controller is shared Rust compiled to WebAssembly for client prediction; the wire protocol is generated from `protocol/schema.json` for both languages (`just gen`).

Prerequisites: Rust (stable) with the `wasm32-unknown-unknown` target, Node.js 24+, pnpm, and `just`.

Commands (these exist exactly as written):
- `just setup` — adds the wasm target and installs web dependencies
- `just run` — builds and starts the game server (ws://127.0.0.1:7878/ws) and the web client; open http://localhost:3000
- `just verify` — the full check suite (format, clippy, Rust tests, TypeScript typecheck, eslint, web tests)
- `just gen` — regenerate protocol code after editing `protocol/schema.json`

Controls (current): WASD move, mouse to look (click the game to capture the mouse), Space jump. Planned: Shift / right-click class ability, E interact, Tab run overlay.

Repo layout: `server/` (Rust workspace: crates `protocol`, `sim`, `sim-wasm`, `server`), `web/` (Next.js client), `protocol/` (schema + golden fixtures), `tools/` (codegen, run, capture, dispatch scripts), `design/` (game data tables, later), `tickets/` (development work log).
