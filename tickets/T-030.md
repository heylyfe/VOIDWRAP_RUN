Game rule (from the human): in multiplayer, a player who walks into the exit beacon (or dies with no lives left)
becomes an invisible SPECTATOR until every other player has finished: they can fly freely and look at the remaining
players. The server already handles who is spectating; you build the client-side camera math and the HUD.

Camera convention used everywhere (web/src/game/input.ts): yaw 0 looks toward -Z, positive yaw turns left
(counter-clockwise seen from above); forward vector on the ground = (-sin(yaw), 0, -cos(yaw)), right = (cos(yaw), 0,
-sin(yaw)). Pitch: positive = looking DOWN (the third-person camera sits above and behind the player); range -1.3..1.3.

## Task

   ```ts
   export interface FlyKeys { forward: boolean; back: boolean; left: boolean; right: boolean; up: boolean; down: boolean; fast: boolean }
   export interface Vec { x: number; y: number; z: number }
   export const FLY_SPEED = 16;        // units/s
   export const FAST_MULTIPLIER = 2.2;
   /** Moves `pos` (mutated) for one frame of free flight. Forward/back follow the full look direction (yaw AND pitch:
    *  looking down while pressing forward descends); left/right strafe on the horizontal plane; up/down move along
    *  world Y. Diagonals are normalised; dt is clamped to [0, 0.1]. */
   export function flyStep(pos: Vec, keys: FlyKeys, yaw: number, pitch: number, dt: number): void;
   /** Camera position for following a player: orbit `distance` units behind/above `target` along the look direction. */
   export function followCamera(target: Vec, yaw: number, pitch: number, distance: number): Vec;
   /** Next index when cycling through `count` followable players; null -> 0; wraps; count 0 -> null. */
   export function nextFollow(current: number | null, count: number): number | null;
   ```
   Note: with pitch positive meaning "looking down", the look direction is
   (-sin(yaw)*cos(pitch), -sin(pitch), -cos(yaw)*cos(pitch)).
