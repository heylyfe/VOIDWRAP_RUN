# Ticket T-086: radar and HUD modules

Purchasable radar modules sold in the shop (T-082). Each is an upgrade item with a clear counter-value
against specific registry enemies.

## The modules

1. **Gift arrow**: a better gift direction hint - a compass arrow to the nearest uncollected gift,
   with distance.
2. **Enemy radar**: pings the positions of permanents on a cooldown (a short pulse, not a permanent
   wallhack).
3. **Ground-hazard radar**: shows tripmines and trampolines (T-087) within a radius.

## Requirements

- Each module is an item in `design/content.json`'s shop section, purchasable and equippable.
- The HUD renders each module's state: the arrow, the ping cooldown, the hazard overlay.
- Each module names the registry enemies it counters, and the shop text says so.
- Vitest coverage for each HUD rendering and for the cooldown behaviour.
- Server-authoritative: the server decides what a player may see; the client only draws it.

## Output format

Complete files with `=== FILE: <path> ===` ... `=== END FILE ===`, or single functions with
`=== FN: <path> :: <name> ===` ... `=== END FN ===`. Allowed paths: `web/src/`,
`server/crates/server/src/`, `design/content.json`.

Do not touch `protocol/` unless a client-visible field is genuinely required; if it is, change
`protocol/schema.json` and note that the lead must run `just gen` and `just fixtures`. No new deps.

## Done when

The web suite and `cargo test -p server` pass, clippy is clean, and each module is purchasable and
equippable end to end. Put the cooldowns and radii you chose in NOTES.
