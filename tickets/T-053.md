## Task
1. Replace the behaviour model with one state machine per enemy id (pallbearer, snapshrike, moteling, rift_warden,
   gale_wight, lantern_leech, turret, mimic, corrupter) exactly as specified (states, timings, speeds, radii,
   targeting, through-platform rules, telegraphs). `EnemyParams` becomes
   `{ behavior: u8 (BEHAVIOR_* per id, 0..=8 in the order above), speed_mul: f32, size: f32, grace_ticks: u32 }`
   (speed_mul and size come from content + curses; per-enemy numbers live in your code as named constants).
   Enemies that do not pass through platforms collide with platform AABBs (stop/slide).
2. Stepping API (the server will call exactly this; keep it):

       pub struct PlayerSense { pub id: u32, pub feet: Vec3, pub vel: Vec3, pub warded: bool }
       pub enum HazardEffect {
           Kill { player: u32, cause: u8 },                     // DEATH_ENEMY or DEATH_PROJECTILE
           Shove { player: u32, vel: Vec3, stagger_ticks: u8 }, // knockback velocity (u/s), stagger in server ticks
       }
       impl Hazards {
           pub fn new() -> Self; pub fn reset(&mut self);
           pub fn step(&mut self, enemies: &mut [Enemy], world: &World, level: &LevelData,
                       players: &[PlayerSense], pickups: &[Vec3], speed_mul: f32) -> Vec<HazardEffect>;
           pub fn pulse(&mut self, enemies: &mut [Enemy], centre: &Vec3, radius: f32); // Bulwark pulse
           pub fn views(&self, enemies: &[Enemy]) -> Vec<EnemyView>;  // id/kind/pos/radius/state/target/prog/flags
           pub fn projectiles(&self) -> Vec<ProjectileView>;
           pub fn tiles(&self) -> Vec<TileState>;                     // crumble WARN/GONE + corrupter FRETTED
       }

   `pickups` = positions of gifts collected this tick (lantern_leech). `speed_mul` = phase-2 multiplier (1.0 or
   1.1). Warded players are immune to every Kill and Shove EXCEPT gale_wight shell blasts. Dormant enemies and the
   first 4.0 s of a level never hurt. EnemyView.state: ENEMY_DORMANT, ENEMY_HUNTING (roaming), ENEMY_DISGUISED
   (mimic cached), ENEMY_TELEGRAPH (any wind-up: prog 0..255 across the telegraph, target = anchor), ENEMY_ATTACK
   (lunge/dash/fall/sting/shove in progress, target = anchor), ENEMY_RECOVER (cooldowns). Set ENEMY_FLAG_HEAVY while
   a heavy wind-up runs. Moteling's stillness check uses the player's horizontal speed. Gale wight shells are
   projectiles while falling; a platform top between the shell and the ground stops them.
3. Heavy mutex (design 2.1), crumble tiles (keep today's behaviour), corrupter fretting (TILE_FRETTED for 8 s).
4. Tests per enemy: state sequence and timings; a telegraph of >= 0.6 s before every lethal effect; targeting rule;
   counterplay works (standing still survives moteling, a perpendicular step dodges snapshrike, shelter blocks a
   shell, breaking line of sight stops a turret hit). Mutex soak: never two heavy wind-ups at once over 10 000 ticks
   with all nine enemies x2 and 4 moving players. Warded immunity rules. Non-lethal enemies never emit Kill.
   Determinism (same inputs -> same effects). No NaN.
