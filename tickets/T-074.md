# Ticket T-074: enemy batch A - Rewind, Warden, Peal, Kite, Static

Implement five enemies from the frozen registry (`design/ENEMY_REGISTRY.md`) in the shared `sim` crate.
The registry is the contract: cue tier, min level, cap, tags, class interactions and synergy hooks are
already decided there. You implement behaviour, telegraphs and tests.

## What exists (verified)

- `server/crates/sim/src/rules.rs` holds the enemy model: `BEHAVIOR_*` constants (0..8), `EnemyParams`,
  `Brain` (one variant per behaviour), one `*Brain` struct per enemy with its own phase enum and
  timers, and `Brain::for_behavior` which maps a constant to a brain.
- Enemies are stepped by the server each tick; the brain decides movement and attack state, and the
  server turns that into `EnemyView` for clients.
- `design/content.json` already has registry entries for all five (added by T-072) with their params.
- The sim crate is compiled to WASM: no wall clock, no `sin`/`cos`/`powf` in the step path, only
  `+ - * / sqrt`. Determinism is mandatory.

## The five behaviours (from the registry and the research pack)

1. **Rewind** (`BEHAVIOR_REWIND`, cue 2, min level 1, cap 2). Spawns about 3 s after the collect phase
   starts. Replays the nearest player's path from about 1.5 s ago: it follows a recorded trail of that
   player's positions, and touching it is lethal. Counter: sharp direction changes and jump pads.
   It must visibly tremble before it starts moving (the tier-2 telegraph).
2. **Warden** (`BEHAVIOR_WARDEN`, cue 2, min level 2, cap 1). Patrols the densest gift cluster. When a
   player takes a guarded gift it winds up for about 1.5 s (whirring) and lunges at that player. In the
   collapse phase it frenzies (faster, shorter windup). Counter: bait with one player, collect with
   another.
3. **Peal** (`BEHAVIOR_PEAL`, cue 1, min level 4, cap 1). Teleports near the closest player every ~6 s
   and rings. Harmless UNLESS the target is OVERTUNED, in which case the ring kills. The chime is the
   tier-1 telegraph.
4. **Kite** (`BEHAVIOR_KITE`, cue 2, min level 6, cap 1). Locks onto the player farthest from the group
   with a lock-on tone, drops a delayed strike marker that tracks that player, then detonates blast
   rings. Counter: keep moving, break line of sight with height and ramps.
5. **Static** (`BEHAVIOR_STATIC`, cue 3, min level 5, cap 2). Static when near, then dashes, strikes,
   goes invisible and teleports away, switching to the next-closest player. Nearly invisible in fog, so
   fog becomes a threat. Tier-3 ambient telegraph.

## Requirements

- One module per enemy is preferred: `server/crates/sim/src/enemies/rewind.rs` etc., with
  `server/crates/sim/src/enemies/mod.rs` re-exporting them, and `rules.rs` wiring the new `Brain`
  variants. If you keep them in `rules.rs` instead, say why in NOTES.
- Every new public item gets a doc comment.
- OVERTUNED is a new debuff flag on the player state (Coil inflicts it in T-075). Add the flag and the
  timer here, with Peal reading it. Keep it out of the protocol unless a client must render it; if it
  must, change `protocol/schema.json` and note that the lead must run `just gen` and `just fixtures`.
- Class interactions from the registry: implement the ones the registry marks as counters or immunity.
- Telegraphs must be visible at gameplay distance: each enemy exposes its phase so the client can draw
  it. Do not invent new protocol messages beyond what the registry requires.
- Tests per enemy: the happy path, the counter working, and the telegraph phase lasting the tier's
  minimum. Deterministic, no sleeps.

## Output format

Complete files with `=== FILE: <path> ===` ... `=== END FILE ===`, or single functions with
`=== FN: <path> :: <name> ===` ... `=== END FN ===`. Allowed paths: anything under
`server/crates/sim/src/`, plus `protocol/schema.json` if a client-visible field is genuinely needed.

Do not touch `web/`, `design/`, or `server/crates/server/`. No new dependencies.

## Done when

`cargo test -p sim` passes with the new tests, `cargo clippy -p sim --all-targets -- -D warnings` is
clean, and each of the five has a working telegraph and counter. Put the tuning numbers you chose in
NOTES - balancing happens later, so pick sane values and move on.
