`web/src/content.ts` (current):
```ts
// Typed access to design/content.json: draft cards (enemies, upgrades, curses) and per-theme screen grades.
// The Rust server reads the same file, so card ids, numbers and text can never drift between client and server.
import content from "../../design/content.json";

export type Mods = Partial<Record<string, number>>;

export interface EnemyCard {
  id: string;
  name: string;
  flavor: string;
  behavior: string;
  threat: number;
  params: { speed: number; aggro: number; grace_s: number; size: number };
}

export interface ModCard {
  id: string;
  name: string;
  flavor: string;
  effect: string;
  rarity: "common" | "rare";
  mods: Mods;
  threat?: number;
  greater?: boolean;
}

export interface ScreenGrade {
  tint: string;
  tint_strength: number;
  saturation: number;
  contrast: number;
  brightness: number;
  vignette_color: string;
  vignette_darkness: number;
  aberration: number;
  grain: number;
  scanlines: number;
}

export const ENEMIES: readonly EnemyCard[] = content.enemies;
export const UPGRADES: readonly ModCard[] = content.upgrades as ModCard[];
export const CURSES: readonly ModCard[] = content.curses as ModCard[];
const GRADES: Record<string, ScreenGrade> = content.grades;

/** Card kinds as used on the wire (protocol DraftCard.kind). */
export const CARD_ENEMY = 0;
export const CARD_UPGRADE = 1;
export const CARD_CURSE = 2;

export type AnyCard =
  | { kind: typeof CARD_ENEMY; card: EnemyCard }
  | { kind: typeof CARD_UPGRADE; card: ModCard }
  | { kind: typeof CARD_CURSE; card: ModCard };

/** Resolve a wire card (kind + id) to its content; null for unknown ids (never trust the wire blindly). */
export function lookupCard(kind: number, id: string): AnyCard | null {
  if (kind === CARD_ENEMY) {
    const card = ENEMIES.find((e) => e.id === id);
    return card ? { kind: CARD_ENEMY, card } : null;
  }
  if (kind === CARD_UPGRADE) {
    const card = UPGRADES.find((e) => e.id === id);
    return card ? { kind: CARD_UPGRADE, card } : null;
  }
  if (kind === CARD_CURSE) {
    const card = CURSES.find((e) => e.id === id);
    return card ? { kind: CARD_CURSE, card } : null;
  }
  return null;
}

const NEUTRAL_GRADE: ScreenGrade = {
  tint: "#ffffff",
  tint_strength: 0,
  saturation: 0,
  contrast: 0,
  brightness: 0,
  vignette_color: "#000000",
  vignette_darkness: 0.4,
  aberration: 0.001,
  grain: 0.02,
  scanlines: 0,
};

export function gradeForTheme(themeId: string): ScreenGrade {
  return GRADES[themeId] ?? NEUTRAL_GRADE;
}
```

`web/src/scene/Effects.tsx` (current):
```tsx
"use client";

import { useMemo } from "react";
import type { JSX } from "react";
import {
  Bloom,
  ChromaticAberration,
  EffectComposer,
  Noise,
  Vignette,
} from "@react-three/postprocessing";
import { BlendFunction } from "postprocessing";
import { Vector2 } from "three";

export function Effects(): JSX.Element {
  const aberrationOffset = useMemo(() => new Vector2(0.0011, 0.0008), []);

  return (
    <EffectComposer multisampling={0} enableNormalPass={false}>
      <Bloom
        mipmapBlur
        luminanceThreshold={0.8}
        luminanceSmoothing={0.2}
        intensity={1.2}
        radius={0.75}
      />
      <ChromaticAberration
        offset={aberrationOffset}
        radialModulation
        modulationOffset={0.3}
      />
      <Vignette offset={0.3} darkness={0.5} />
      <Noise
        opacity={0.025}
        premultiply
        blendFunction={BlendFunction.SOFT_LIGHT}
      />
    </EffectComposer>
  );
}
```

postprocessing's custom-effect API (6.x): `class X extends Effect { constructor() { super("Name", fragmentShader, {
uniforms: new Map<string, Uniform>([...]) , blendFunction: BlendFunction.NORMAL }) } }` where fragmentShader defines
`void mainImage(const in vec4 inputColor, const in vec2 uv, out vec4 outputColor)`; effects can also declare
`void mainUv(inout vec2 uv)` - not needed here. Uniforms are THREE.Uniform. Render it in r3f with
`<primitive object={effect} />` inside the EffectComposer (or `wrapEffect` from @react-three/postprocessing).
Colours: build THREE.Color from hex (three converts sRGB->linear); the effect runs in linear space on the HDR input
before tone mapping is applied by the composer's output, so treat values as linear.

## Task
1. New `web/src/scene/ColorGrade.tsx`:
   - `export class ColorGradeEffect extends Effect` with uniforms uTint (Color), uTintStrength, uSaturation,
     uContrast, uBrightness, uVignetteColor (Color), uVignetteDarkness, uScanlines, uTime, uResolutionY.
     Fragment: c = inputColor.rgb; brightness: c += uBrightness; contrast: c = (c - 0.5) * (1 + uContrast) + 0.5 applied
     on luminance-preserving form (do it per channel but clamp c >= 0); saturation: mix(luma, c, 1 + uSaturation);
     tint: soft-light-style mix toward uTint: c = mix(c, c * (uTint * 2.0) , uTintStrength) clamped >= 0 (keep it simple,
     document the formula); vignette: r = distance(uv, 0.5) * 1.41; v = smoothstep(0.35, 1.0, r) * uVignetteDarkness;
     c = mix(c, uVignetteColor, v); scanlines: c *= 1 - uScanlines * (0.5 + 0.5 * sin(uv.y * uResolutionY * 3.14159 +
     uTime * 2.0)) (only when uScanlines > 0; thin lines at ~1 per 2 px). outputColor = vec4(c, inputColor.a).
   - `export function applyGrade(effect: ColorGradeEffect, grade: ScreenGrade): void` sets the uniforms (no allocations
     beyond Color.set).
   - `export function ColorGrade(props: { grade: ScreenGrade }): JSX.Element` - creates the effect once, applies the
     grade when it changes, and smoothly blends from the previous grade to the new one over 0.6 s when the level theme
     changes (lerp numeric uniforms and Color.lerp in useFrame, through a ref to the effect; no allocations: keep
     preallocated start/target Colors in refs). Updates uTime and uResolutionY (from `useThree((s) => s.size.height)`).
     Disposes the effect on unmount.
