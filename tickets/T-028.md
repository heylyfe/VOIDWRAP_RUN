Game flow (from the human): lobby (players stand on the spawn hub) -> select enemies / upgrades / curses -> press
Continue -> a random map is generated -> players spawn -> collect all normal gifts -> golden gifts (currency) appear ->
beacon -> back to the lobby to draft again. At the start of a run the lobby offers 4 enemy cards (choose 2: "which
enemies hunt you") AND 3 reward cards (choose 1: upgrades help, curses hurt but make the run richer). Between levels only
3 reward cards are offered; every 10th level they are greater curses. In co-op every player votes; after submitting,
a player waits for the others.

```ts
// Typed access to design/content.json: draft cards (enemies, upgrades, curses) and per-theme screen grades.
// The Rust server reads the same file, so card ids, numbers and text can never drift between client and server.
import content from "../../design/content.json";

export type Mods = Partial<Record<string, number>>;

export interface EnemyCard {
  id: string;
  name: string;
  flavor: string;
  behavior: string;
  threat: number;
  params: { speed: number; aggro: number; grace_s: number; size: number };
}

export interface ModCard {
  id: string;
  name: string;
  flavor: string;
  effect: string;
  rarity: "common" | "rare";
  mods: Mods;
  threat?: number;
  greater?: boolean;
}

export interface ScreenGrade {
  tint: string;
  tint_strength: number;
  saturation: number;
  contrast: number;
  brightness: number;
  vignette_color: string;
  vignette_darkness: number;
  aberration: number;
  grain: number;
  scanlines: number;
}

export const ENEMIES: readonly EnemyCard[] = content.enemies;
export const UPGRADES: readonly ModCard[] = content.upgrades as ModCard[];
export const CURSES: readonly ModCard[] = content.curses as ModCard[];
const GRADES: Record<string, ScreenGrade> = content.grades;

/** Card kinds as used on the wire (protocol DraftCard.kind). */
export const CARD_ENEMY = 0;
export const CARD_UPGRADE = 1;
export const CARD_CURSE = 2;

export type AnyCard =
  | { kind: typeof CARD_ENEMY; card: EnemyCard }
  | { kind: typeof CARD_UPGRADE; card: ModCard }
  | { kind: typeof CARD_CURSE; card: ModCard };

/** Resolve a wire card (kind + id) to its content; null for unknown ids (never trust the wire blindly). */
export function lookupCard(kind: number, id: string): AnyCard | null {
  if (kind === CARD_ENEMY) {
    const card = ENEMIES.find((e) => e.id === id);
    return card ? { kind: CARD_ENEMY, card } : null;
  }
  if (kind === CARD_UPGRADE) {
    const card = UPGRADES.find((e) => e.id === id);
    return card ? { kind: CARD_UPGRADE, card } : null;
  }
  if (kind === CARD_CURSE) {
    const card = CURSES.find((e) => e.id === id);
    return card ? { kind: CARD_CURSE, card } : null;
  }
  return null;
}

const NEUTRAL_GRADE: ScreenGrade = {
  tint: "#ffffff",
  tint_strength: 0,
  saturation: 0,
  contrast: 0,
  brightness: 0,
  vignette_color: "#000000",
  vignette_darkness: 0.4,
  aberration: 0.001,
  grain: 0.02,
  scanlines: 0,
};

export function gradeForTheme(themeId: string): ScreenGrade {
  return GRADES[themeId] ?? NEUTRAL_GRADE;
}
```

## Task
1. `web/src/hud/draftSelection.ts` (pure):
   `export function toggleSelection(selected: readonly number[], index: number, cards: readonly { kind: number }[], enemyPicks: number, rewardPicks: number): number[]`
   - enemy cards (kind 0) and reward cards (kind 1/2) are limited separately: selecting beyond the limit for that group
     replaces the OLDEST selection in the same group; clicking a selected card deselects it; out-of-range index -> unchanged.
   `export function selectionComplete(selected, cards, enemyPicks, rewardPicks): boolean` - exact counts per group.
2. `web/src/hud/DraftCard.tsx`: `export function DraftCard(props: { kind: number; id: string; selected: boolean; hotkey: number; onToggle: () => void }): JSX.Element`
   - looks the card up with `lookupCard`; unknown -> a muted "Unknown card" tile (still clickable-safe).
   - Enemy: name, flavor (italic, muted), behavior line, threat as 5 pips (filled red), label "HUNTER".
   - Upgrade: cyan accent, label "UPGRADE" + rarity badge, effect line prominent, flavor muted.
   - Curse: red accent, label "CURSE" (or "GREATER CURSE" with a stronger glowing border), effect line, threat pips.
   - Selected state: thick accent border + slight scale-up + check mark; hotkey badge (1-9) in a corner.
   - A real `<button type="button" aria-pressed={selected}>`, ~15rem wide, readable at a glance.
3. `web/src/hud/DraftScreen.tsx`:
   `export function DraftScreen(props: { cards: readonly { kind: number; id: string }[]; enemyPicks: number; rewardPicks: number; nextLevel: number; currency: number; lives: number; waiting: boolean; onSubmit: (picks: number[]) => void }): JSX.Element`
   - full-screen overlay (`pointer-events-auto`, `bg-black/55` + backdrop blur, scrollable on small screens),
     `data-testid="draft-screen"`; header "LEVEL {nextLevel}" with currency (gold icon) and lives.
   - Section "WHO HUNTS YOU - choose {enemyPicks}" (only if there are enemy cards) and section "TAKE ONE FROM THE VOID -
     choose {rewardPicks}"; each card gets a hotkey 1..n in display order; number keys toggle; Enter submits when
     complete (window keydown listener in useEffect, removed on unmount, ignore key repeat).
   - Continue button `data-testid="draft-continue"`, disabled until `selectionComplete`; on click calls
     `onSubmit(selected sorted ascending)`. When `waiting` is true: cards disabled, button replaced by
     "Waiting for other players..." (`data-testid="draft-waiting"`).
   - Selection state resets when the `cards` prop identity changes (use a key on an inner component, NOT setState in
     an effect).
4. `web/src/hud/RunStatus.tsx`: `export function RunStatus(props: { currency: number; lives: number; enemies: readonly string[]; curses: readonly string[]; upgrades: readonly string[] }): JSX.Element`

     then chips for each drafted enemy (red), curse (dark red) and upgrade (cyan); each chip shows the card name and, on
     hover/focus, a tooltip with its behavior/effect text (CSS-only tooltip via group-hover is fine). pointer-events only
