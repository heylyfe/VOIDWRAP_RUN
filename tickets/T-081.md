# Ticket T-081: voting conformance kit (black-box)

A runnable kit that proves the voting core behaves, without reading its source. Work from the
behaviour described here and in `design/ENEMY_REGISTRY.md`; if the implementation and this description
disagree, this description wins and you report the mismatch.

## The kit

`tools/voting-conformance/run.mjs`, Node built-ins only, no new dependencies, no build step. It takes
the server's WebSocket URL via `--url` or `VOTING_URL`, drives real clients, and prints
`PASS/FAIL - <check>` per check. Exit 0 only on a full pass. Skip cleanly (print "skipped", exit 0)
when no URL is given, so `just verify` stays green by default.

## Checks

1. A vote session opens at level 1 and at every level, during the collapse window.
2. Three options are offered, each with an id, a name and a kind.
3. Majority wins: with three clients voting 2-1, the 2-option wins.
4. A tie goes to the host's vote; with no host vote the server picks deterministically (same seed and
   level give the same winner on a re-run).
5. The winner becomes permanent: it appears in the next level's spawn set and stays for later levels.
6. Cap-aware pool building: an option whose `selection_cap` is already reached is never offered.
7. Pool scaling: a level-1 session never offers an enemy whose `min_level` is above 1.
8. Overflow: when every entry is capped, the options are temporary and no new permanent is added.
9. Rejoin safety: a client that disconnects and reconnects keeps its vote.
10. The countdown closes the session and a late vote is rejected.

## Must fail on violations

Ship a `--selftest` mode that runs the kit against deliberately broken stubs (majority inverted, tie
ignored, cap ignored, permanence dropped, rejoin forgotten, late vote accepted) and requires each
violation to trip its paired check. Exit 0 only when the faithful stub passes AND every violation
fails.

## Output format

Complete files with `=== FILE: <path> ===` ... `=== END FILE ===`. Allowed paths: anything under
`tools/voting-conformance/`.

Do not touch `server/`, `web/`, or `design/`. No new dependencies.

## Done when

The kit passes against the real voting core, fails against each violating stub, and `just verify` stays
green with the kit skipped by default. Put the check list and the selftest result in NOTES.
