# Enemy registry — frozen contract

**Status: FROZEN (T-072).** This document plus the `enemies` array in `design/content.json` is the
single source of truth for enemy selection. T-074, T-075, T-078, T-080 and T-085 read it; none of
them may add a field, a tag, a class relation or a synergy effect on their own. Changing the shape
means a new ticket that edits this file, `design/content.json`, `server/crates/server/src/content.rs`
and `tools/validate-content.mjs` in the same commit.

The registry is **data**. Nothing here is code, and nothing here may be computed at runtime from
another field: every value below is written out per entry and validated.

---

## 1. Entry shape

Every enemy, existing and new, has exactly one entry in `design/content.json` → `enemies[]`:

| field | type | required | meaning |
|---|---|---|---|
| `id` | string, `^[a-z][a-z0-9_]{1,31}$` | yes | stable id; equals `params.behavior`; array order is the network kind index |
| `name` | string, ≤ 24 chars | yes | plain, what-it-does name; must stay green under `tools/check-names.mjs` |
| `flavor` | string, ≤ 70 chars | yes | one line of voice |
| `behavior` | string, ≤ 110 chars | yes | player-facing instruction: what to do about it |
| `threat` | integer 1..5 | yes | design weight, used for balance review only — never for pool filtering |
| `cue_tier` | integer 1..3 | yes | telegraph class (§2) |
| `min_level` | integer ≥ 1 | yes | first level the enemy may be offered (§3) |
| `selection_cap` | integer 1..2 | yes | permanent copies allowed in one run (§4) |
| `tags` | array of strings | yes, ≥ 1 | closed vocabulary (§5) |
| `class_interactions` | object | yes (may be `{}`) | class id → relation (§6) |
| `synergy_hooks` | array of objects | yes (may be `[]`) | declarative hooks (§7) |
| `params` | object | yes | `speed`, `aggro`, `grace_s`, `size`, `behavior` — unchanged, owned by the sim (§8) |

`params.behavior` must equal `id`. The sim maps behaviour strings to `BEHAVIOR_*` constants; a
string it does not know yet degrades to `BEHAVIOR_PALLBEARER`. That is the intended state for the
eleven entries added in T-072 until T-074 / T-075 land their constants.

---

## 2. `cue_tier` — what the implementation owes the player

The tier is a promise about the **wind-up**, not about the damage.

**Tier 1 — under 1 s telegraph (instant dodge).**
- The tell is on the enemy body itself (shape, colour, aperture); no floor decal is required.
- The wind-up is visible for **0.35 s – 0.95 s** before the hit resolves.
- The punish must be avoidable with **one dash from a standing start** at the enemy's design speed.
- No audio-only tells. No hit that resolves in the same tick the tell appears.

**Tier 2 — 1 s – 2 s (reposition).**
- A floor decal or aim line appears for **1.0 s – 2.0 s** before the hit resolves.
- The decal shows the **exact hit volume**; the player can leave it by walking, no dash needed.
- The decal persists for the whole wind-up and is removed on resolve.

**Tier 3 — ambient (awareness only).**
- No per-attack telegraph. The enemy has a **persistent state cue** (aura, fog density, looping
  sound) that changes when it is active, so the player can read the level without watching it.
- The punish is a **zone or state the player can leave at any time**. A tier-3 enemy may never
  land an unavoidable instant hit.

---

## 3. `min_level`

1-based. Level 1 is the first draft after the lobby. An entry with `min_level = N` is **invisible to
the pool** for every level `< N`. It is not a difficulty rating and it is not a threat gate: it is
the first level at which the enemy may be *offered*.

---

## 4. `selection_cap`

The maximum number of **permanent** copies of that enemy that may exist at once in a single run.
`1` = unique, `2` = a pair is allowed.

- Copies granted by milestones (`milestone_6`, `milestone_10`, `milestone_20`) are permanent and
  count against the cap. A grant that would exceed the cap grants nothing for that enemy.
- **Temporary** copies (overflow, §9) never count against the cap.

---

## 5. `tags` — closed vocabulary

| tag | meaning |
|---|---|
| `fog` | changes what the player can see (fog density, sight radius) |
| `ambush` | attacks from a position the player cannot see: above, behind cover, or disguised |
| `collapse` | removes or falsifies floor |
| `chase` | moves toward the player with intent |
| `zone` | owns an area the player must leave or cross |
| `debuff` | applies a persistent negative state (slow, silence, timer stall) |
| `summon` | creates other actors |
| `small` | body under 0.8 units; counts for `chorus_needs_small_pair` |
| `large` | body 1.2 units or more; blocks sight lines |
| `loot` | interacts with gifts / loot |

Tags are semantic, not a size mirror: `small` and `large` are applied when the size class matters to
the pool, so a 0.7-unit trap that is not a body may carry neither. Tags are unordered and unique per
entry.

---

## 6. `class_interactions` — closed vocabulary

Keys are class ids from `design/content.json` → `classes[]`. **The file ships exactly four classes**
(`striker`, `grappler`, `bulwark`, `glider`) and `tools/validate-content.mjs` pins the array to those
four; there is no fifth class. The vocabulary is closed at four until a fifth class ships, at which
point this section and `CLASS_IDS` in `content.rs` grow together.

Values:

| relation | meaning | pool effect |
|---|---|---|
| `counters` | the class's base ability fully answers the signature threat, no card needed | none |
| `immune` | the signature effect is never applied to that class | none; the implementation must skip the effect |
| `ignores` | the enemy never selects that class — it is not attracted to them | the enemy is **removed from the pool** for a run of that class |

A class that is absent from the object is **neutral**: no counter, no immunity, no exclusion.

---

## 7. `synergy_hooks` — declarative, closed effect set

A hook is data. The engine reads it; it never executes content.

```json
{ "with": "coil", "effect": "peal_lethal_when_overtuned" }
{ "requires": { "tag": "small", "count": 2 }, "effect": "chorus_needs_small_pair" }
```

Exactly one of `with` / `requires` is present per hook.

- `with` — another enemy id. The hook fires when that enemy is a **permanent** in the run.
- `requires` — `{ tag, count }`. The hook is satisfied when the run already holds at least `count`
  permanents carrying `tag`. The level gate is the owning entry's own `min_level`.

Hooks are declared on the enemy that **owns** the effect, never on both sides.

### Closed effect set

| effect | semantics |
|---|---|
| `peal_lethal_when_overtuned` | If `coil` is a permanent in the run and Peal's zone has reached its final ring, the final ring deals lethal damage instead of the debuff. Without Coil the final ring only debuffs. |
| `infection_pauses_timer` | While Blight's infection is on the player, the named enemy's signature timer (Rewind's rewind clock, Kite's tether clock) does not advance. It resumes at its previous value when the infection clears. |
| `chorus_needs_small_pair` | Chorus is only a candidate when the run already holds at least 2 permanents tagged `small`. |

Adding a fourth effect is a spec change. The engine must reject an unknown effect name at load
(`Content::load`) and at validation time (`tools/validate-content.mjs`).

---

## 8. `params`

`speed`, `aggro`, `grace_s`, `size`, `behavior` — unchanged by T-072 and owned by the sim. The
registry never rewrites them; `RunMods::enemy_params` applies the curses on top. `grace_s` is 4.0
for every entry (nothing damages anyone in the first 4 s).

---

## 9. Pool rules (the voting system)

`permanents(run, id)` = permanent copies of `id` currently in the run. Temporary copies are not
counted anywhere in this section.

```
pool(level, run) =
  enemies
    .filter(e => e.min_level <= level)
    .filter(e => permanents(run, e.id) < e.selection_cap)
    .filter(e => every hook with `requires` is satisfied)
    .filter(e => e.class_interactions[run.class] !== "ignores")
    .sort(by min_level ascending, then by content order)
```

- **`min_level`** removes entries above the current level. The pool is never padded with them.
- **`selection_cap` + current permanent count** removes entries already at their cap.
- **`requires` hooks** remove entries whose prerequisite permanents are not held yet.
- **Class composition** removes entries that `ignores` the run's class. `counters` and `immune`
  never filter; they are balance and implementation facts.
- **Order** is deterministic: `min_level` ascending, ties broken by content order. No RNG.

The vote draws the first `POOL_OFFER = 3` candidates in that order. (`POOL_OFFER` is a T-072
invention; the vote UI in T-078 may change the count, never the order.)

### Empty pool — overflow

If the filtered pool is empty, the run does **not** skip the enemy slot. It drafts a **temporary**
enemy instead:

1. Take the permanent enemy with the highest `min_level <= level` (tie → content order) and add one
   temporary copy for the next level only.
2. If the run holds no permanents yet (level 1), take the lowest-`min_level` entry that is not
   excluded by class composition.
3. Temporary copies: do not count toward `selection_cap`, do not satisfy `requires` hooks, are
   removed when the level ends, and are never offered to the vote.

## 11. Contracts for the eleven new entries (T-074 / T-075)

Behaviour is implemented in T-074 / T-075. This section is the contract they build against; the
`behavior` string in `content.json` is the player-facing version of the same thing.

### `rewind` — Rewind (cue 2, min 1, cap 2, chase/zone)
- Cue: a floor mark at the enemy's remembered position, 1.2 s, shrinking onto the exact return point.
- Punish: on close, the enemy snaps to the mark and drags the player to it. A reposition, not damage.
- Counter: Striker dash breaks the drag; Grappler is immune (the grapple anchors).

### `warden` — Warden (cue 2, min 2, cap 1, chase/loot)
- Cue: a ring around the gift it guards, 1.5 s, before its reach extends to the ring edge.
- Punish: standing inside the ring when it closes costs a life-chunk and knocks the gift away.
- Counter: Grappler pulls the gift out; Bulwark is immune (the ward shoves it off its post).

### `peal` — Peal (cue 1, min 4, cap 1, zone/debuff)
- Cue: the bell body opens for 0.6 s before each ring.
- Punish: each ring widens the zone; the third ring is the final one.
- Counter: Bulwark is immune (the ward ignores the ring); Glider crosses above it.
- Hook: with `coil` permanent, the final ring is lethal instead of a debuff.

### `kite` — Kite (cue 2, min 6, cap 1, chase/zone)
- Cue: the tether line brightens for 1.4 s before it tightens.
- Punish: the tether tightens while the player runs away; it snaps for damage at full tension.
- Counter: Striker and Grappler both close the gap and cut the line.

### `static` — Static (cue 3, min 5, cap 2, fog/chase)
- Cue: ambient — fog density rises around it and a loop plays while it is tracking.
- Punish: it follows the sound of running; the fog it leaves slows the player inside it.
- Counter: Glider is never attracted (silent); Bulwark is immune (the ward grounds it).

### `blight` — Blight (cue 3, min 8, cap 1, debuff/chase)
- Cue: ambient — infected ground is discoloured and spreads one tile per beat.
- Punish: crossing infected ground applies the infection; it spreads and stalls timers.
- Counter: Glider is immune (airborne); Grappler crosses above the infection.
- Hook: while infected, `rewind` and `kite` timers do not advance.

### `metronome` — Metronome (cue 1, min 10, cap 1, zone/debuff)
- Cue: the arm flashes 0.5 s before each swing.
- Punish: the safe half of the floor alternates on the count; the wrong half debuffs.
- Counter: Glider crosses the swing; Bulwark is immune (the ward ignores the beat).

### `overlook` — Overlook (cue 2, min 12, cap 1, zone/chase)
- Cue: a sight line to the player, 1.6 s, before the mark lands.
- Punish: marks the player for every other enemy on the level.
- Counter: Striker closes and kills it; Glider is never attracted (out of its floor-bound sight).

### `chorus` — Chorus (cue 3, min 10, cap 1, summon/small)
- Cue: ambient — the singers are audible before they are visible.
- Punish: summons small singers that copy the player's last move one beat late.
- Counter: Striker kills the singers; Bulwark is immune (the ward shoves them off).
- Hook: `chorus_needs_small_pair` — only a candidate once two `small` permanents are held.

### `coil` — Coil (cue 1, min 4, cap 2, zone/debuff)
- Cue: the coil visibly winds, 0.8 s, before release.
- Punish: winds tighter every second the player stays near it, then releases a zone debuff.
- Counter: Striker dashes out; Glider is never attracted (never stands in it).

### `lure` — Lure (cue 1, min 3, cap 2, fog/ambush/collapse)
- Cue: the false floor shimmers for 0.7 s before it opens.
- Punish: paints a false floor over the void; stepping on it drops the player.
- Counter: Glider is immune (crosses above); Grappler pulls past it.

## 12. Migration notes

- The nine M3 entries keep their `id`, `name`, `flavor`, `behavior`, `threat` and `params` byte for
  byte. Only the registry fields were added.
- The eleven new entries are **appended** after `corrupter`: array order is the network kind index,
  so the first nine positions must never move.
- `params.behavior` for the new entries equals their id. Until T-074 / T-075 add the matching
  `BEHAVIOR_*` constants, `behavior_from_str` degrades them to `BEHAVIOR_PALLBEARER` — the entries
  load and validate, they simply reuse the pallbearer brain.
- `small` was added to the four existing bodies under 0.8 units (`snapshrike`, `moteling`,
  `lantern_leech`, `mimic`) so that `chorus_needs_small_pair` is satisfiable: without them only
  Chorus itself carries `small`, and Chorus has `selection_cap` 1.

    /// so this field is not wired into `EnemyParams` (speed comes from the sim plus the `enemy_speed_mul` curse).
    #[allow(dead_code)]
    pub speed: f32,
    /// Design aggro radius; kept in the file for reference. The sim owns targeting ranges, so this is not wired in either.
    #[allow(dead_code)]
    pub aggro: f32,
    pub grace_s: f32,
    pub size: f32,
    /// "pallbearer" | "snapshrike" | ... | "corrupter"; unknown values degrade to pallbearer.
    #[serde(default = "pallbearer")]
    pub behavior: String,
}

/// A declarative pool requirement: the run must already hold `count` permanents carrying `tag`.
#[derive(Debug, Clone, Deserialize)]
pub struct SynergyRequires {
    pub tag: String,
    pub count: u8,
}

/// One declarative synergy hook. Exactly one of `with` (pairwise) or `requires` (self) is set.
#[derive(Debug, Clone, Deserialize)]
pub struct SynergyHook {
    /// Another enemy id; the hook fires while that enemy is a permanent in the run.
    #[serde(default)]
    pub with: Option<String>,
    /// A tag/count prerequisite on the run's own permanents.
    #[serde(default)]
    pub requires: Option<SynergyRequires>,
    /// One of `SYNERGY_EFFECTS`.
    pub effect: String,
}

#[derive(Debug, Clone, Deserialize)]
pub struct EnemyDef {
    pub id: String,
    /// Player-facing name; plain, what-it-does (tools/check-names.mjs).
    #[serde(default)]
    pub name: String,
    /// 1 = under 1 s telegraph, 2 = 1-2 s, 3 = ambient. Defaults to 3 so an older file promises nothing.
    #[serde(default = "default_cue_tier")]
    pub cue_tier: u8,
    /// First level the enemy may be offered.
    #[serde(default = "default_min_level")]
    pub min_level: u8,
    /// Permanent copies allowed in one run (1 or 2).
    #[serde(default = "default_selection_cap")]
    pub selection_cap: u8,
    /// Closed vocabulary, see `ENEMY_TAGS`.
    #[serde(default)]
    pub tags: Vec<String>,
    /// class id -> "counters" | "immune" | "ignores"; absent classes are neutral.
    #[serde(default)]
    pub class_interactions: BTreeMap<String, String>,
    /// Declarative only; the engine reads these, it never executes content.
    #[serde(default)]
    pub synergy_hooks: Vec<SynergyHook>,
    pub params: EnemyStats,
}

#[derive(Debug, Clone, Deserialize)]
pub struct ModCard {
    pub id: String,
    pub mods: BTreeMap<String, f32>,
    #[serde(default)]
    pub greater: bool,
}

/// A playable class; order in content must match the CLASS_* protocol constants.
#[derive(Debug, Clone, Deserialize)]
pub struct ClassDef {
    pub id: String,
}

/// An item sold in the lobby shop. `kind`: "life" | "reroll" | "mods".
#[derive(Debug, Clone, Deserialize)]
pub struct ShopItemDef {
    pub id: String,
    pub cost: u32,
    pub stock: u8,
    pub kind: String,
    #[serde(default)]
    pub mods: BTreeMap<String, f32>,
}

/// A level event (EVENT_*); `friction_mul` only means something for EVENT_ICE.
#[derive(Debug, Clone, Deserialize)]
pub struct EventDef {
    pub id: String,
    pub event: u8,
    #[serde(default = "one")]
    pub friction_mul: f32,
}

/// An interactable shrine; its id matches nothing on the wire (levelgen altar ids do).
#[derive(Debug, Clone, Deserialize)]
pub struct AltarDef {
    pub id: String,
}

#[derive(Debug, Clone, Deserialize)]
pub struct Content {
    pub enemies: Vec<EnemyDef>,
    pub upgrades: Vec<ModCard>,
    pub curses: Vec<ModCard>,
    #[serde(default)]
    pub classes: Vec<ClassDef>,
    #[serde(default)]
    pub shop: Vec<ShopItemDef>,
    #[serde(default)]
    pub events: Vec<EventDef>,
    #[serde(default)]
    pub altars: Vec<AltarDef>,
}

impl Content {
    /// Parse the embedded content. A malformed file is a build-time mistake caught by tests and `just verify`.
    pub fn load() -> Result<Content, String> {
        let c: Content = serde_json::from_str(CONTENT_JSON).map_err(|e| format!("design/content.json: {e}"))?;
        if c.enemies.len() < 4 || c.upgrades.len() < 3 || c.curses.iter().filter(|k| !k.greater).count() < 3 {
            return Err("design/content.json: not enough cards for a draft".into());
        }
        if c.curses.iter().filter(|k| k.greater).count() < 3 {
            return Err("design/content.json: need at least 3 greater curses".into());
        }
        // Enemies: the frozen registry contract (design/ENEMY_REGISTRY.md). Ids are unique and every
        // registry field sits inside its closed vocabulary; the sim still owns the behaviour itself.
        let mut enemy_ids = std::collections::BTreeSet::new();
        for enemy in &c.enemies {
            if !enemy_ids.insert(enemy.id.as_str()) {
                return Err(format!("design/content.json: duplicate enemy {}", enemy.id));
            }
        }
        for enemy in &c.enemies {
            let id = enemy.id.as_str();
            if !(1..=3).contains(&enemy.cue_tier) {
                return Err(format!(
                    "design/content.json: enemy {id}: cue_tier {} not in 1..=3",
                    enemy.cue_tier
                ));
            }
            if enemy.min_level < 1 {
                return Err(format!("design/content.json: enemy {id}: min_level must be >= 1"));
            }
            if !(1..=2).contains(&enemy.selection_cap) {
                return Err(format!(
                    "design/content.json: enemy {id}: selection_cap {} not in 1..=2",
                    enemy.selection_cap
                ));
            }
            if enemy.tags.is_empty() {
                return Err(format!("design/content.json: enemy {id}: needs at least one tag"));
            }
            let mut tags = std::collections::BTreeSet::new();
            for tag in &enemy.tags {
                if !ENEMY_TAGS.contains(&tag.as_str()) {
                    return Err(format!("design/content.json: enemy {id}: unknown tag {tag}"));
                }
                if !tags.insert(tag.as_str()) {
                    return Err(format!("design/content.json: enemy {id}: duplicate tag {tag}"));
                }
            }
            for (class, relation) in &enemy.class_interactions {
                if !CLASS_IDS.contains(&class.as_str()) {
                    return Err(format!("design/content.json: enemy {id}: unknown class {class}"));
                }
                if !CLASS_RELATIONS.contains(&relation.as_str()) {
                    return Err(format!(
                        "design/content.json: enemy {id}: unknown class relation {relation}"
                    ));
                }
            }
            for hook in &enemy.synergy_hooks {
                if !SYNERGY_EFFECTS.contains(&hook.effect.as_str()) {
                    return Err(format!(
                        "design/content.json: enemy {id}: unknown synergy effect {}",
                        hook.effect
                    ));
                }
                match (&hook.with, &hook.requires) {
                    (Some(other), None) => {
                        if !enemy_ids.contains(other.as_str()) {
                            return Err(format!(
                                "design/content.json: enemy {id}: synergy with unknown enemy {other}"
                            ));
                        }
                    }
                    (None, Some(requires)) => {
                        if !ENEMY_TAGS.contains(&requires.tag.as_str()) {
                            return Err(format!(
                                "design/content.json: enemy {id}: unknown requirement tag {}",
                                requires.tag
                            ));
                        }
                        if requires.count < 1 {
                            return Err(format!(
                                "design/content.json: enemy {id}: requirement count must be >= 1"
                            ));
                        }
                    }
                    _ => {
                        return Err(format!(
                            "design/content.json: enemy {id}: synergy hook needs exactly one of `with` or `requires`"
                        ));
                    }
                }
            }
        }
        // Shop: unique ids, known kinds, known mod keys.
        let mut shop_ids = std::collections::BTreeSet::new();
        for item in &c.shop {
            if !shop_ids.insert(item.id.as_str()) {
                return Err(format!("design/content.json: duplicate shop item {}", item.id));
            }
            match item.kind.as_str() {
                "life" | "reroll" => {}
                "mods" => {
                    if item.mods.is_empty() {
                        return Err(format!("design/content.json: shop item {} has no mods", item.id));
                    }
                    for key in item.mods.keys() {
                        if !KNOWN_MODS.contains(&key.as_str()) {
                            return Err(format!("design/content.json: shop item {}: unknown mod {key}", item.id));
                        }
                    }
                }
                other => {
                    return Err(format!(
                        "design/content.json: shop item {}: unknown kind {other}",
                        item.id
                    ));
                }
            }
        }
        // Events: unique event numbers and a sane friction multiplier.
        let mut seen_events = std::collections::BTreeSet::new();
        for event in &c.events {
            if !seen_events.insert(event.event) {
                return Err(format!("design/content.json: duplicate event {}", event.event));
            }
            if !event.friction_mul.is_finite() || event.friction_mul <= 0.0 {
                return Err(format!(
                    "design/content.json: event {} has invalid friction_mul",
                    event.id
                ));
            }
        }
        // Classes: the first four, in order, are the CLASS_* protocol constants.
        if !c.classes.is_empty() {
            let valid = c.classes.len() >= CLASS_IDS.len()
                && c.classes.iter().zip(CLASS_IDS).all(|(class, want)| class.id == want);
            if !valid {
                return Err("design/content.json: classes must start with striker, grappler, bulwark, glider".into());
            }
        }
        // Altars: unique ids.
        let mut altar_ids = std::collections::BTreeSet::new();
        for altar in &c.altars {
            if !altar_ids.insert(altar.id.as_str()) {
                return Err(format!("design/content.json: duplicate altar {}", altar.id));
            }
        }
        Ok(c)
    }

    /// Index of an enemy in content order (sent to clients as `EnemyView.kind`) and its definition.
    pub fn enemy(&self, id: &str) -> Option<(usize, &EnemyDef)> {
        self.enemies.iter().enumerate().find(|(_, e)| e.id == id)
    }

    pub fn upgrade(&self, id: &str) -> Option<&ModCard> {
        self.upgrades.iter().find(|e| e.id == id)
    }

    pub fn curse(&self, id: &str) -> Option<&ModCard> {
        self.curses.iter().find(|e| e.id == id)
    }

    /// Shop item definition by id.
    pub fn shop_item(&self, id: &str) -> Option<&ShopItemDef> {
        self.shop.iter().find(|e| e.id == id)
    }

    /// Event definition (EVENT_*) by event number, e.g. `EVENT_ICE`.
    pub fn event(&self, event: u8) -> Option<&EventDef> {
        self.events.iter().find(|e| e.event == event)
    }
}

/// Accumulated effect of every upgrade and curse drafted this run (multipliers multiply, additions add).
#[derive(Debug, Clone, PartialEq)]
pub struct RunMods {
    pub run_speed_mul: f32,
    pub jump_mul: f32,
    pub gravity_mul: f32,
    pub dash_speed_mul: f32,
    pub dash_cooldown_mul: f32,
    pub air_jumps: u32,
    pub gift_radius_mul: f32,
    /// Clustered Gifts curse: multiplier on the sim's minimum gift spacing (1.0 = scattered default).
    /// Values below 1.0 place gifts closer together (the sim clamps to [0.25, 1.0]; this side to GENERIC_MUL_RANGE).
    pub gift_spacing_mul: f32,
    pub extra_lives: u32,
    pub enemy_speed_mul: f32,
    pub enemy_aggro_mul: f32,
    pub enemy_grace_mul: f32,
    pub enemy_size_mul: f32,
    pub extra_enemies: u32,
    pub fog_density_mul: f32,
    pub beacon_radius_mul: f32,
}

impl Default for RunMods {
    fn default() -> Self {
        RunMods {
            run_speed_mul: 1.0,
            jump_mul: 1.0,
            gravity_mul: 1.0,
            dash_speed_mul: 1.0,
            dash_cooldown_mul: 1.0,
            air_jumps: 0,
            gift_radius_mul: 1.0,
            gift_spacing_mul: 1.0,
            extra_lives: 0,
            enemy_speed_mul: 1.0,
            enemy_aggro_mul: 1.0,
            enemy_grace_mul: 1.0,
            enemy_size_mul: 1.0,
            extra_enemies: 0,
            fog_density_mul: 1.0,
            beacon_radius_mul: 1.0,
        }
    }
}

/// Hard caps on stacked effects so no combination of cards can make a level impossible or absurd.
const MOVE_MUL_RANGE: (f32, f32) = (0.8, 1.8);
const JUMP_MUL_RANGE: (f32, f32) = (0.85, 1.6);
const GRAVITY_MUL_RANGE: (f32, f32) = (0.5, 1.25);
const GENERIC_MUL_RANGE: (f32, f32) = (0.4, 2.5);
const MAX_AIR_JUMPS: u32 = 3;
const MAX_EXTRA_ENEMIES: u32 = 6;
const MAX_LIVES: u32 = 9;

impl RunMods {
    /// Fold one card's mods in. Unknown keys are ignored (the content validator rejects them before shipping).
    pub fn apply(&mut self, mods: &BTreeMap<String, f32>) {
        for (key, &v) in mods {
            let v = if v.is_finite() { v } else { continue };
            match key.as_str() {
                "run_speed_mul" => self.run_speed_mul *= v,
                "jump_mul" => self.jump_mul *= v,
                "gravity_mul" => self.gravity_mul *= v,
                "dash_speed_mul" => self.dash_speed_mul *= v,
                "dash_cooldown_mul" => self.dash_cooldown_mul *= v,
                "gift_radius_mul" => self.gift_radius_mul *= v,
                "gift_spacing_mul" => self.gift_spacing_mul *= v,
                "enemy_speed_mul" => self.enemy_speed_mul *= v,
                "enemy_aggro_mul" => self.enemy_aggro_mul *= v,
                "enemy_grace_mul" => self.enemy_grace_mul *= v,
                "enemy_size_mul" => self.enemy_size_mul *= v,
                "fog_density_mul" => self.fog_density_mul *= v,
                "beacon_radius_mul" => self.beacon_radius_mul *= v,
                "air_jumps_add" => self.air_jumps = self.air_jumps.saturating_add(v.max(0.0) as u32),
                "extra_lives_add" => self.extra_lives = self.extra_lives.saturating_add(v.max(0.0) as u32),
                "extra_enemies_add" => self.extra_enemies = self.extra_enemies.saturating_add(v.max(0.0) as u32),
                _ => {}
            }
        }
        self.clamp();
    }

    fn clamp(&mut self) {
        let c = |v: f32, (lo, hi): (f32, f32)| v.clamp(lo, hi);
        self.run_speed_mul = c(self.run_speed_mul, MOVE_MUL_RANGE);
        self.jump_mul = c(self.jump_mul, JUMP_MUL_RANGE);
        self.gravity_mul = c(self.gravity_mul, GRAVITY_MUL_RANGE);
        self.dash_speed_mul = c(self.dash_speed_mul, GENERIC_MUL_RANGE);
        self.dash_cooldown_mul = c(self.dash_cooldown_mul, GENERIC_MUL_RANGE);
        self.gift_radius_mul = c(self.gift_radius_mul, GENERIC_MUL_RANGE);
        // The curse ships 0.6; values above 1.0 (spreading) are folded away by the sim's 1.0 cap.
        self.gift_spacing_mul = c(self.gift_spacing_mul, GENERIC_MUL_RANGE);
        self.enemy_speed_mul = c(self.enemy_speed_mul, GENERIC_MUL_RANGE);
        self.enemy_aggro_mul = c(self.enemy_aggro_mul, GENERIC_MUL_RANGE);
        self.enemy_grace_mul = c(self.enemy_grace_mul, GENERIC_MUL_RANGE);
        self.enemy_size_mul = c(self.enemy_size_mul, GENERIC_MUL_RANGE);
        self.fog_density_mul = c(self.fog_density_mul, GENERIC_MUL_RANGE);
        self.beacon_radius_mul = c(self.beacon_radius_mul, GENERIC_MUL_RANGE);
        self.air_jumps = self.air_jumps.min(MAX_AIR_JUMPS);
        self.extra_enemies = self.extra_enemies.min(MAX_EXTRA_ENEMIES);
        self.extra_lives = self.extra_lives.min(MAX_LIVES);
    }

    /// The movement tuning shared with the client predictor. `friction_mul` is 1.0 here;
    /// the level event (EVENT_ICE) overrides it, see `Run::tuning`.
    pub fn tuning(&self) -> Tuning {
        Tuning {
            run_speed_mul: self.run_speed_mul,
            jump_mul: self.jump_mul,
            gravity_mul: self.gravity_mul,
            dash_speed_mul: self.dash_speed_mul,
            dash_cooldown_mul: self.dash_cooldown_mul,
            air_jumps: self.air_jumps as u8,
            friction_mul: 1.0,
        }
    }

    /// Enemy parameters after curses: size scaled, grace converted to ticks, speed multiplier from the speed curse.
    /// Per-enemy design numbers live in the sim; `speed_mul` starts at the curse multiplier (1.0 by default).
    pub fn enemy_params(&self, stats: &EnemyStats) -> EnemyParams {
        EnemyParams {
            behavior: behavior_from_str(&stats.behavior),
            speed_mul: self.enemy_speed_mul,
            size: stats.size * self.enemy_size_mul,
            grace_ticks: secs_to_ticks(stats.grace_s * self.enemy_grace_mul),
        }
    }
}

/// Map a behavior string to a BEHAVIOR_* constant; content order is the protocol's behaviour order.
/// Unknown strings degrade to pallbearer.
fn behavior_from_str(s: &str) -> u8 {
    match s {
        "pallbearer" => BEHAVIOR_PALLBEARER,
        "snapshrike" => BEHAVIOR_SNAPSHRIKE,
        "moteling" => BEHAVIOR_MOTELING,
        "rift_warden" => BEHAVIOR_RIFT_WARDEN,
        "gale_wight" => BEHAVIOR_GALE_WIGHT,
        "lantern_leech" => BEHAVIOR_LANTERN_LEECH,
        "turret" => BEHAVIOR_TURRET,
        "mimic" => BEHAVIOR_MIMIC,
        "corrupter" => BEHAVIOR_CORRUPTER,
        _ => BEHAVIOR_PALLBEARER,
    }
}

/// Seconds to whole ticks at TICK_HZ, rounded, at least 1 tick (and NaN-safe).
fn secs_to_ticks(s: f32) -> u32 {
    (s * protocol::TICK_HZ as f32).round().max(1.0) as u32
}

    #[test]
    fn mods_stack_and_clamp_to_playable_limits() {
        let mut m = RunMods::default();
        let slow: BTreeMap<String, f32> = [("run_speed_mul".to_string(), 0.5)].into();
        for _ in 0..5 {
            m.apply(&slow);
        }
        assert_eq!(m.run_speed_mul, MOVE_MUL_RANGE.0);
        let jumps: BTreeMap<String, f32> = [("air_jumps_add".to_string(), 2.0)].into();
        m.apply(&jumps);
        m.apply(&jumps);
        assert_eq!(m.air_jumps, MAX_AIR_JUMPS);
        assert_eq!(m.tuning().air_jumps, 3);
        let nan: BTreeMap<String, f32> = [("jump_mul".to_string(), f32::NAN)].into();
        m.apply(&nan);
        assert_eq!(m.jump_mul, 1.0);
    }

    #[test]
    fn enemy_params_map_behavior_strings() {
        let m = RunMods::default();
        let stats = |behavior: &str| EnemyStats {
            speed: 0.0,
            aggro: 0.0,
            grace_s: 2.0,
            size: 0.7,
            behavior: behavior.to_string(),
        };
        let cases = [
            ("pallbearer", BEHAVIOR_PALLBEARER),
            ("snapshrike", BEHAVIOR_SNAPSHRIKE),
            ("moteling", BEHAVIOR_MOTELING),
            ("rift_warden", BEHAVIOR_RIFT_WARDEN),
            ("gale_wight", BEHAVIOR_GALE_WIGHT),
            ("lantern_leech", BEHAVIOR_LANTERN_LEECH),
            ("turret", BEHAVIOR_TURRET),
            ("mimic", BEHAVIOR_MIMIC),
            ("corrupter", BEHAVIOR_CORRUPTER),
        ];
        for (name, want) in cases {
            assert_eq!(m.enemy_params(&stats(name)).behavior, want, "{name}");
        }
        // Unknown behavior degrades to pallbearer.
        assert_eq!(m.enemy_params(&stats("wraith")).behavior, BEHAVIOR_PALLBEARER);
        // Ticks are rounded and at least 1 (even for zero/negative seconds).
        let tiny = EnemyStats {
            speed: 1.0,
            aggro: 1.0,
            grace_s: 0.01,
            size: 1.0,
            behavior: "pallbearer".to_string(),

        let p = m.enemy_params(&tiny);

        let negative = EnemyStats {
            speed: 1.0,
            aggro: 1.0,
            grace_s: -5.0,
            size: 1.0,
            behavior: "pallbearer".to_string(),
        };
        assert_eq!(m.enemy_params(&negative).grace_ticks, 1);
    }

  "enemy_speed_mul", "enemy_aggro_mul", "enemy_grace_mul", "enemy_size_mul", "fog_density_mul", "beacon_radius_mul",
  "gift_spacing_mul"];
const ADD = ["air_jumps_add", "extra_lives_add", "extra_enemies_add"];
// Movement floors/ceilings that keep every level completable (1.5-unit steps, 4-unit gaps).
const PLAYABLE = { run_speed_mul: [0.8, 2], jump_mul: [0.85, 2], gravity_mul: [0.4, 1.25] };
const THEMES = ["ashfall", "fluxbloom", "slagstone", "tidegrave"];

const ID = /^[a-z][a-z0-9_]{1,31}$/;

function checkId(where, id) {
  if (!ID.test(id ?? "")) err(`${where}: bad id ${JSON.stringify(id)}`);
  if (ids.has(id)) err(`${where}: duplicate id ${id}`);
  ids.add(id);
}
function checkText(where, field, v, max) {
  if (typeof v !== "string" || v.trim() === "") err(`${where}.${field}: missing`);
  else if (v.length > max) err(`${where}.${field}: ${v.length} > ${max} chars`);
}
function checkMods(where, mods, greater) {
  if (!mods || typeof mods !== "object" || Object.keys(mods).length === 0) return err(`${where}: no mods`);
  const [lo, hi] = greater ? [0.4, 2.0] : [0.5, 1.6];
  for (const [k, v] of Object.entries(mods)) {
    if (MUL.includes(k)) {
      if (typeof v !== "number" || v < lo || v > hi) err(`${where}.${k}=${v} outside [${lo}, ${hi}]`);
      const p = PLAYABLE[k];
      if (p && (v < p[0] || v > p[1])) err(`${where}.${k}=${v} breaks playability [${p[0]}, ${p[1]}]`);
    } else if (ADD.includes(k)) {
      if (!Number.isInteger(v) || v < 0 || v > 3) err(`${where}.${k}=${v} must be an integer 0..3`);
    } else err(`${where}: unknown mod key ${k}`);
  }
}

  let doc;

    doc = JSON.parse(readFileSync(file, "utf8"));

    if (e.code === "ENOENT") continue; // a missing pattern file is not an error
    err(`${file}: ${e.message}`);
    continue;

    err(`${file}: expected a "chunks" or "patterns" array`);
