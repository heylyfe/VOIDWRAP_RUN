## Task
1. Bulwark (design section 3): grounded-only cast, 8-frame windup (immobile), 96-frame ward (`ward_frames` counts
   down; rooted: horizontal speed 0, gravity off - hover in place, no jump/dash/ability), cooldown 16.0 s from cast
   start in `ability_cooldown_frames` (scaled by the existing dash cooldown multiplier and clamping). The radial
   pulse and the immunity are applied by the SERVER (it reads `ward_frames > 0`); the controller only exposes
   `pub fn bulwark_pulse_frame(state: &ControllerState) -> bool` (true on the first ward frame).
2. Jump pads: landing on (or standing on) a PLATFORM_JUMP_PAD sets `vel.y = PAD_LAUNCH_VEL` (16.0) and multiplies
   horizontal velocity by 0.6, once per contact (not every frame while overlapping); pads stay solid.
3. Step-up (amendment A2): when horizontal movement is blocked by a solid platform whose top is <= STEP_HEIGHT
   (0.55) above the feet and the player box fits at the new height, move the player up onto it (keep horizontal
   motion); only when grounded or within coyote frames. Stairs of 0.5 u risers must be walkable at full run speed
   without jumping; a 0.6 u ledge must still block.
4. Stagger: while `stagger_frames > 0` (set by the server together with a knockback velocity), ignore move input,
   jump, ability and dash; keep the current velocity with gravity and normal collision and apply only ground
   friction (so a shove carries the player); decrement each frame.
5. Fretted tiles: TILE_FRETTED platforms stay solid. While standing on one: max run speed x0.6 and BTN_ABILITY is
   ignored. Add `World::tile_state(platform_index) -> u8`.
6. Spatial grid (amendment A7): World builds a uniform grid (cell 8 u, integer cell coords, deterministic iteration
   order, e.g. sorted Vec of platform indices per cell) and collision/ground queries test only platforms in the
   cells overlapped by the player's swept box. Results must be identical to brute force (add a test comparing both
   over random boxes on a 500-platform world).
7. Keep everything else unchanged (striker, grappler, glider, ice friction, tiles). Update sim-wasm only if an API it
   uses changes. Tests for every rule above, incl. a 0.5 u staircase climbed by holding forward, pad apex ~4.0 u
   (+-0.1), stagger carrying the player, bulwark rooted mid-run, fretted slowdown + ability lock, grid equivalence.
   The playthrough bot test (`server/crates/sim/tests/playthrough.rs`) must keep passing.
