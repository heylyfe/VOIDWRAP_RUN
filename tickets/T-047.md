Facts:
- Level 1's lobby is the plain first round (no cards: `cards.length === 0`); that is where each player picks a
  CLASS (`CLASSES` in content.ts, index = CLASS_* value). The server accepts a class choice only there.
- From level 2 on, lobbies show draft cards AND a shop (`store.shop`: `ShopItem { id, cost, stock }`, details by id
  in `SHOP`). Money is `RunInfo.currency` (team-wide). Buying sends one item id; the server checks money/stock and
  answers with a fresh Shop + RunState + a Notice.
- Notices (`store.notices`, newest last): NOTICE_ALTAR ids = [upgrade id, curse id] ("The altar gave you X ... and
  Y"); NOTICE_BOUGHT ids = [shop item id]; NOTICE_EVENT ids = [event id from EVENTS] (show the event name + banner
  text big, like a level banner).
- The game program serves `GET /api/host` and `POST /api/host` `{ "enable": bool }` returning
  `{ hosting: boolean, port: number, lan: string[], public: string | null, upnp: "off" | "trying" | "open" |
  "failed", message: string }`. These answer 403 when the page was opened from another computer (a friend's game):
  then hide hosting controls. Friends join a host by opening `http://<address>:<port>/` - the host's program serves
  the whole game.
