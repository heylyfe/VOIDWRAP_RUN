# Pattern format (binding for the pattern catalog and the composition engine)

**Status: FROZEN (T-069).** This document **SUPERSEDES `design/CHUNK_FORMAT.md`** for all new
content. `CHUNK_FORMAT.md` stays in the tree as the historical record of the geometry rules that
this document inherits; where the two disagree, this document wins.

A **pattern** is the same data fragment as a chunk, extended with the closed-vocabulary tags the
composition engine reasons about. The 25 chunks in `design/chunks.json` are **valid patterns** as
soon as their `tags` array gains the new tag entries described in §4 — no other change is required.

---

## 1. Catalog files

The catalog is split across three files so that two authors can work in parallel without touching
the same file:

| File | Owner | Shape |
| --- | --- | --- |
| `design/chunks.json` | frozen (25 legacy chunks) | `{ "version": 1, "chunks": [ ... ] }` |
| `design/patterns-a.json` | T-070 | `{ "version": 1, "patterns": [ ... ] }` |
| `design/patterns-b.json` | T-071 | `{ "version": 1, "patterns": [ ... ] }` |

Rules:

* The loader accepts **both** key names (`chunks` and `patterns`) in any of the three files.
* The three arrays are concatenated in the order above into one catalog at load time.
* A **missing file is not an error**: the game must still run with only `chunks.json`.
* **Duplicate `id` across files is an error.** `validate-content` reports it and refuses to build.
  Ids are unique across the whole merged catalog, not per file.
* `version` must be `1`. Unknown top-level keys are ignored.

---

## 2. The pattern object

```jsonc
{
  "id": "pt07_ember_span",              // unique across all three files, [a-z0-9_]
  "name": "Ember Span",
  "role": "hub" | "path" | "junction" | "dead_end",
  "min_level": 1,                       // first level this pattern may appear on
  "difficulty": 1,                      // 1..3
  "tags": [ ... ],                      // see §4; free-form legacy tags are still allowed
  "platforms": [ ... ],                 // unchanged from CHUNK_FORMAT.md
  "sockets": [ ... ],                   // unchanged, see §5
  "gift_slots": [ ... ],                // unchanged, see §6
  "enemy_slots": [ ... ],               // hub only: exactly 8
  "altar_slots": [ ... ],               // unchanged, see §6
  "beacon": [x, y, z] | null            // hub only: beacon dais top centre
}
```

`id`, `name`, `role`, `min_level`, `difficulty`, `platforms`, `sockets`, `gift_slots`,
`enemy_slots`, `altar_slots` and `beacon` keep exactly the meaning and the constraints they have in
`CHUNK_FORMAT.md`. This document adds only the tag vocabulary (§4) and the composition constraints
(§7).

## 3. Tag namespaces

All pattern tags live in the single existing `tags` array. The new fields are carried as
**prefixed entries** so the on-disk schema does not change and legacy free-form tags stay harmless:

```
theme:<value>     visual / atmospheric identity      (closed vocabulary, §4.1)
mech:<value>      what the player does there         (closed vocabulary, §4.2)
hazard:<value>    reserved for later waves           (closed vocabulary, §4.3)
<anything else>   legacy free-form tag, ignored by the engine
```

* A pattern **must** declare at least one `theme:` tag and at least one `mech:` tag.
* A pattern may declare **at most two** `theme:` tags and **at most three** `mech:` tags.
* `hazard:` tags are optional and **nothing consumes them yet**. Declaring them is legal and
  forward-compatible; the engine parses and stores them and ignores them.
* Unknown values after a known prefix are ignored by the loader (forward compatibility), but
  `validate-content` reports them as warnings so typos do not silently disappear.
* Duplicate entries of the same value are collapsed.

### 3.1 Theme vocabulary (closed — 8 values)

| Value | Meaning |
| --- | --- |
| `ember` | Fire, ash, warm orange light, scorched stone. |
| `void` | Starless emptiness, black sky, floating debris, low ambient light. |
| `frost` | Ice, snow, cold blue light, brittle surfaces. |
| `ruin` | Broken masonry, collapsed halls, rubble, faded banners. |
| `garden` | Overgrown vegetation, water, soft green light, roots. |
| `machine` | Gears, pistons, hot metal, pipes, industrial noise. |
| `spire` | Verticality, thin bridges, height, wind, distant sky. |
| `hollow` | Caverns, echoes, darkness below, dripping stone. |

### 3.2 Mechanic vocabulary (closed — 10 values)

| Value | Meaning |
| --- | --- |
| `climb` | Net vertical gain; the player goes up. |
| `drop` | Net vertical loss; the player goes down. |
| `span` | A gap crossed by a jump or a short bridge. |
| `bounce` | Relies on a jump pad or a bounce surface. |
| `crawl` | Low headroom, tight corridors, slow movement. |
| `gauntlet` | Sustained pressure: enemies, hazards, no safe footing. |
| `rest` | Safe footing, no enemies, a place to breathe. |
| `loot` | Dense gift slots; the reward room. |
| `fork` | A real choice of route; **junction role only**. |
| `dead_end` | Terminates a branch; **dead_end role only**. |

### 3.3 Hazard vocabulary (closed — 4 values, reserved)

| Value | Meaning | Consumed today |
| --- | --- | --- |
| `trampoline` | A bounce surface. | no |
| `tripmine` | A triggered trap. | no |
| `fog` | Vision-limiting volume. | no |
| `crumble` | A surface that collapses. | no |

## 4. Geometry (inherited, restated)

Everything in `CHUNK_FORMAT.md` §Coordinates, §Widths, §Ramps and §Stacking applies unchanged.
The rules the composition engine and the assembler depend on are restated here so an author never
has to open the old file:

* Chunk-local, right-handed, **Y up**. Facing: `N = +Z`, `E = +X`, `S = -Z`, `W = -X`, pointing
  **out** of the pattern.
* The footprint is the XZ bounding box of the pattern's platforms.
* A socket's `pos` lies **exactly on the footprint edge** on the side it faces, and `pos.y` is the
  walking height (a platform top) at that socket.
* A platform whose top is at `pos.y` touches that edge across the **full socket width**, centred on
  `pos`, so two joined patterns form a continuous walkway.
* **A pattern must have at least one socket.** Hubs have 3–4, paths 2, junctions 3–4, dead ends 1.
* Socket `width` is an integer `>= 3` and `<= 8`. Walkways are `>= 3` u across the direction of
  travel; hubs and junctions are `>= 6` u. Two sockets only stitch when their widths are equal or
  differ by at most 1 u — the assembler centres the narrower walkway on the wider one.
* Platforms are axis-aligned boxes; ramps are axis-aligned wedges with rise/run `<= 0.5`, run
  `>= 2.0` u and width `>= 3` u. **Stairs do not exist anywhere in the game.**
* Stacking: two platforms of different layers that overlap in XZ need `>= 4.0` u of vertical
  clearance between the lower one's top and the upper one's bottom. This holds between patterns
  too, so a pattern must not rely on a neighbour's volume.
* Jumps inside a pattern stay inside the design hop envelope (M3_DESIGN 4.1, "design max gap").

## 5. Spawn points

Unchanged from `CHUNK_FORMAT.md`:

* `gift_slots`: `{ "pos": [x, y, z], "elevated": false }`, `pos.y = platform top + 0.3`, on
  `NORMAL` platforms only (never `CRUMBLE` / `JUMP_PAD`), `>= 2.0` u apart, `>= 0.5` u from platform
  edges, spaced about every 2.0–2.6 u along the walkway.
* `enemy_slots`: `[x, y, z]`, **hub only, exactly 8**, arranged around the beacon.
* `altar_slots`: `[x, y, z]` on `NORMAL` tops, `>= 1.5` u from platform edges.
* `beacon`: `[x, y, z]`, **hub only**, beacon dais top centre. Non-hub patterns write `null` or
  omit the key.

## 6. Composition constraints (the engine honours these)

The composition engine builds a `CompositionPlan` — an ordered list of pattern ids — from
`(seed, level, players)` **before any geometry is placed**, then the growth walk drains that plan.
The constraints below are the contract between the catalog and that engine.

### 6.1 Role order

| Role | May appear | May follow | May be followed by |
| --- | --- | --- | --- |
| `hub` | exactly once, **first** | — | `path`, `junction` |
| `path` | any number | `hub`, `path`, `junction` | `path`, `junction`, `dead_end` |
| `junction` | up to the level's junction budget | `hub`, `path`, `junction` | `path`, `junction`, `dead_end` |
| `dead_end` | at most one per six patterns | `path`, `junction` | — (terminates the branch) |

A `dead_end` is never placed by the growth walk; the assembler seals leftover sockets with them.
A `hub` is never placed by the growth walk either — it is placed first, at the origin, unrotated.

### 6.2 Run lengths

* **Theme run**: at most **3** consecutive patterns may share a theme tag. The fourth must
  introduce a different theme.
* **Mechanic run**: at most **2** consecutive patterns may share the same `mech:` tag.
* **Level length**: the plan is `10 + level` entries, clamped to `[10, 48]`.

### 6.3 Tag interactions

* Two `rest` patterns may **not** be adjacent.
* Two `gauntlet` patterns may **not** be adjacent.
* `fork` may only appear on a `junction` role pattern.
* `dead_end` may only appear on a `dead_end` role pattern.
* `loot` may appear at most once every three patterns.
* A pattern with `mech:climb` must actually gain height; a pattern with `mech:drop` must actually
  lose height. `mech:span` requires a real gap of at least 2.0 u.
* `hazard:` tags never constrain composition in this wave.

### 6.4 Selection bias

The bag that fills the plan is seeded and integer-only. It:

1. never returns the same pattern twice in a row (hard rule whenever two or more patterns are
   eligible);
2. divides the weight of any pattern seen in the last **6** picks by **32**;
3. adds a bonus to patterns carrying a theme that has been used fewer than **2** times so far in
   the level, so a level has a coherent but varied theme mix;
4. subtracts a small penalty for each difficulty step above the level's tier.

If the catalog carries no pattern tags at all, the engine falls back to the pre-T-069 weighted
pick and the level is assembled exactly as before.

---

## 7. Determinism

Same `(seed, level, players)` must always produce the same plan and the same level. Nothing in the
engine may read the wall clock, and no float transcendental (`sin`, `cos`, `powf`, …) may appear in
the selection path — the sim crate is compiled to `wasm32-unknown-unknown` and must stay bit-exact.
The bag uses integer weights and an integer PRNG only.

### 8.1 A path pattern

```json

  "name": "Ember Span",
  "role": "path",
  "min_level": 1,
  "difficulty": 2,
  "tags": ["theme:ember", "theme:ruin", "mech:span", "mech:climb", "hazard:crumble", "bridge", "gap"],
  "platforms": [
    { "kind": "NORMAL",  "min": [-3.0, 0.0, -4.0], "max": [3.0, 0.5, 4.0] },
    { "kind": "CRUMBLE", "min": [-3.0, 0.0,  4.0], "max": [3.0, 0.5, 8.0] },
    { "kind": "NORMAL",  "min": [-3.0, 0.0,  8.0], "max": [3.0, 0.5, 12.0] }
  ],
  "sockets": [
    { "id": "a", "pos": [0.0, 0.5, -4.0], "facing": "S", "width": 6 },
    { "id": "b", "pos": [0.0, 0.5, 12.0], "facing": "N", "width": 6 }
  ],
  "gift_slots": [
    { "pos": [-1.5, 0.8, 0.0], "elevated": false },
    { "pos": [ 1.5, 0.8, 10.0], "elevated": false }
  ],
  "enemy_slots": [],
  "altar_slots": [[0.0, 0.5, 10.0]],
  "beacon": null
}
```

Why it is legal: footprint is `x ∈ [-3, 3]`, `z ∈ [-4, 12]`; socket `a` sits on the `z = -4` edge
facing `S`, socket `b` on the `z = 12` edge facing `N`, both at walking height `0.5` and both 6 u
wide, matching the 6 u walkway. Gift slots are at `top + 0.3 = 0.8`, on `NORMAL` tops, 10 u apart
and 1.5 u from the side edges. The altar slot is on a `NORMAL` top, 2 u from the `z = 12` edge.
All platforms share one layer, so the stacking rule is vacuous.

## 9. Authoring checklist

Before submitting a pattern:

1. `id` is unique across all three files and matches `[a-z0-9_]+`.
2. At least one `theme:` tag, at least one `mech:` tag, at most two themes, at most three
   mechanics. Every value is from §3.
3. `fork` only on `junction`, `dead_end` only on `dead_end`.
4. At least one socket; every socket sits on the footprint edge it faces, at walking height, with
   `3 <= width <= 8`.
5. Walkways `>= 3` u, hubs and junctions `>= 6` u, ramps within rise/run `<= 0.5`.
6. Gift slots on `NORMAL` tops at `top + 0.3`, `>= 2.0` u apart, `>= 0.5` u from edges.
7. Altar slots on `NORMAL` tops, `>= 1.5` u from edges.
8. Hubs: exactly 8 enemy slots and a beacon. Non-hubs: no enemy slots, `beacon: null`.
9. No reliance on a neighbour's volume for stacking clearance.
10. `cargo run -p <validate-content>` reports no errors and no tag warnings.

//! Pattern metadata, tag-aware selection and composition planning (T-069).
//!
//! A *pattern* is a chunk plus the closed-vocabulary tags described in
//! `design/PATTERN_FORMAT.md`. This module owns three things:
//!
//! * [`PatternMeta`] — the parsed metadata of one pattern.

//!

//! transcendentals, so the module is bit-exact on every target the sim crate is

/// Visual and atmospheric identity of a pattern. Closed vocabulary.
#[derive(Clone, Copy, Debug, PartialEq, Eq, Hash)]
pub enum ThemeTag {
    /// Fire, ash, warm orange light, scorched stone.
    Ember,
    /// Starless emptiness, black sky, floating debris.
    Void,
    /// Ice, snow, cold blue light, brittle surfaces.
    Frost,
    /// Broken masonry, collapsed halls, rubble.
    Ruin,
    /// Overgrown vegetation, water, soft green light.
    Garden,
    /// Gears, pistons, hot metal, pipes.
    Machine,
    /// Verticality, thin bridges, height, wind.
    Spire,
    /// Caverns, echoes, darkness below.
    Hollow,
}

impl ThemeTag {
    /// Every allowed theme, in canonical order.
    pub const ALL: [ThemeTag; 8] = [
        ThemeTag::Ember,
        ThemeTag::Void,
        ThemeTag::Frost,
        ThemeTag::Ruin,
        ThemeTag::Garden,
        ThemeTag::Machine,
        ThemeTag::Spire,
        ThemeTag::Hollow,
    ];

    /// Number of allowed themes.
    pub const COUNT: usize = 8;

    /// The wire name used after the `theme:` prefix in `tags`.
    pub fn as_str(self) -> &'static str {
        match self {
            ThemeTag::Ember => "ember",
            ThemeTag::Void => "void",
            ThemeTag::Frost => "frost",
            ThemeTag::Ruin => "ruin",
            ThemeTag::Garden => "garden",
            ThemeTag::Machine => "machine",
            ThemeTag::Spire => "spire",
            ThemeTag::Hollow => "hollow",
        }
    }

    /// Parses a wire name. Returns `None` for anything outside the vocabulary.
    pub fn parse(name: &str) -> Option<ThemeTag> {
        ThemeTag::ALL.iter().copied().find(|t| t.as_str() == name)
    }

    /// Dense index in `0..COUNT`, used for the per-level theme counters.
    pub fn index(self) -> usize {
        match self {
            ThemeTag::Ember => 0,
            ThemeTag::Void => 1,
            ThemeTag::Frost => 2,
            ThemeTag::Ruin => 3,
            ThemeTag::Garden => 4,
            ThemeTag::Machine => 5,
            ThemeTag::Spire => 6,
            ThemeTag::Hollow => 7,
        }
    }

    /// Inverse of [`ThemeTag::index`]; wraps out-of-range indices.
    pub fn from_index(index: usize) -> ThemeTag {
        ThemeTag::ALL[index % ThemeTag::COUNT]
    }
}

/// The parsed metadata of one pattern.
///
/// Built from a catalog entry's `id`, `role`, `min_level`, `difficulty` and `tags`
/// by [`PatternMeta::from_tags`]. The geometry (`platforms`, `sockets`, slots,
/// `beacon`) stays in the catalog and is not duplicated here.
#[derive(Clone, Debug, PartialEq, Eq)]
pub struct PatternMeta {
    /// Catalog id, unique across the merged catalog.
    pub id: String,
    /// Structural role, shared with the chunk format.
    pub role: ChunkRole,
    /// First level this pattern may appear on.
    pub min_level: u32,
    /// Difficulty tier, `1..=3`.
    pub difficulty: u8,
    /// Theme tags, at least one after parsing.
    pub theme: Vec<ThemeTag>,
    /// Mechanic tags, possibly empty for legacy content.
    pub mechanic: Vec<MechanicTag>,
    /// Hazard tags, reserved for later waves.
    pub hazard: Vec<HazardTag>,
    /// Whether the catalog entry declared at least one explicit pattern tag.
    pub tagged: bool,
}

impl PatternMeta {
    /// Parses the pattern metadata out of a catalog entry's raw tag list.
    ///
    /// Recognised prefixes are `theme:`, `mech:` and `hazard:`; every other tag is
    /// a legacy free-form tag and is ignored. Unknown values after a known prefix
    /// are ignored too, so a newer catalog still loads on an older build.
    ///
    /// A pattern with no `theme:` tag is given a stable default theme derived from
    /// its id, so the theme mixer always has something to work with. Authors must
    /// still declare explicit themes; the default only exists so the 25 legacy
    /// chunks stay valid patterns before T-070/T-071 re-tag them.
    pub fn from_tags(
        id: &str,
        role: ChunkRole,
        min_level: u32,
        difficulty: u8,
        tags: &[String],
    ) -> PatternMeta {
        let mut theme: Vec<ThemeTag> = Vec::new();
        let mut mechanic: Vec<MechanicTag> = Vec::new();
        let mut hazard: Vec<HazardTag> = Vec::new();
        for raw in tags {
            let tag = raw.trim();
            if let Some(rest) = tag.strip_prefix("theme:") {
                if let Some(value) = ThemeTag::parse(rest) {
                    if !theme.contains(&value) {
                        theme.push(value);
                    }
                }
            } else if let Some(rest) = tag.strip_prefix("mech:") {
                if let Some(value) = MechanicTag::parse(rest) {
                    if !mechanic.contains(&value) {
                        mechanic.push(value);
                    }
                }
            } else if let Some(rest) = tag.strip_prefix("hazard:") {
                if let Some(value) = HazardTag::parse(rest) {
                    if !hazard.contains(&value) {
                        hazard.push(value);
                    }
                }
            }
        }
        let tagged = !theme.is_empty() || !mechanic.is_empty() || !hazard.is_empty();
        if theme.is_empty() {
            theme.push(ThemeTag::from_index(default_theme_index(id)));
        }
        PatternMeta {
            id: id.to_string(),
            role,
            min_level,
            difficulty,
            theme,
            mechanic,
            hazard,
            tagged,
        }
    }

    /// Whether this pattern declared at least one explicit `theme:`/`mech:`/`hazard:` tag.
    pub fn is_tagged(&self) -> bool {
        self.tagged
    }

    /// Whether the pattern carries `tag`.
    pub fn has_mechanic(&self, tag: MechanicTag) -> bool {
        self.mechanic.contains(&tag)
    }

    /// Whether the pattern carries `tag`.
    pub fn has_theme(&self, tag: ThemeTag) -> bool {
        self.theme.contains(&tag)
    }

    /// Whether the pattern carries `tag`.
    pub fn has_hazard(&self, tag: HazardTag) -> bool {
        self.hazard.contains(&tag)
    }
}

/// Stable default theme for a pattern that declares none: FNV-1a over the id.
fn default_theme_index(id: &str) -> usize {
    let mut hash: u32 = 0x811C_9DC5;
    for byte in id.as_bytes() {
        hash ^= u32::from(*byte);
        hash = hash.wrapping_mul(0x0100_0193);
    }
    (hash as usize) % ThemeTag::COUNT
}

/// SplitMix32: integer-only, seeded, identical on every target.
struct SplitMix32 {
    state: u32,
}

impl SplitMix32 {
    fn new(seed: u32) -> SplitMix32 {
        SplitMix32 { state: seed }
    }

    fn next_u32(&mut self) -> u32 {
        self.state = self.state.wrapping_add(0x9E37_79B9);
        let mut z = self.state;
        z = (z ^ (z >> 16)).wrapping_mul(0x21F0_AAAD);
        z = (z ^ (z >> 15)).wrapping_mul(0x735A_2D97);
        z ^ (z >> 15)
    }

    /// Uniform value in `0..n`, by rejection so the distribution stays exact.
    fn below(&mut self, n: u32) -> u32 {
        if n <= 1 {
            return 0;
        }
        let zone = u32::MAX - (u32::MAX % n);
        loop {
            let value = self.next_u32();
            if value < zone {
                return value % n;
            }
        }
    }
}

/// Mixes `(seed, level, players)` into the bag seed.
fn mix_seed(seed: u32, level: u32, players: u32) -> u32 {
    let mut hash = seed ^ 0x9E37_79B9;
    hash = hash.wrapping_mul(0x85EB_CA6B) ^ level.wrapping_mul(0xC2B2_AE35);
    hash = hash.wrapping_mul(0x27D4_EB2F) ^ players.wrapping_mul(0x1656_67B1);
    hash ^ (hash >> 15)
}

/// Tuning for [`TagBag`]. All fields are integer so the bag stays bit-exact.
#[derive(Clone, Copy, Debug)]
pub struct TagBagConfig {
    /// How many recent picks count as "recent". Default 6.
    pub history: usize,
    /// Divisor applied to the weight of a recently picked pattern. Default 32.
    pub recent_divisor: u32,
    /// Weight added per missing use of a theme, up to `theme_target`. Default 96.
    pub theme_bonus: u32,
    /// Uses of a theme after which it stops earning a bonus. Default 2.
    pub theme_target: u32,
    /// Weight removed per difficulty step above the level tier. Default 24.
    pub difficulty_penalty: u32,
}

impl Default for TagBagConfig {
    fn default() -> TagBagConfig {
        TagBagConfig {
            history: 6,
            recent_divisor: 32,
            theme_bonus: 96,
            theme_target: 2,
            difficulty_penalty: 24,
        }
    }
}

/// A seeded, tag-aware selection bag.
///
/// The bag never returns the same pattern twice in a row, strongly discourages
/// patterns seen in the last `history` picks, and biases toward themes that are
/// under-represented so far in the level. It is fully deterministic from its seed.
pub struct TagBag {
    rng: SplitMix32,
    cfg: TagBagConfig,
    tier: u32,
    themes: Vec<Vec<ThemeTag>>,
    difficulty: Vec<u8>,
    counts: [u32; ThemeTag::COUNT],
    history: Vec<usize>,
    last: Option<usize>,
    picks: u32,
}

impl TagBag {
    /// Builds a bag over `metas`, seeded by `seed` and biased against patterns
    /// whose difficulty exceeds `tier`.
    pub fn new(seed: u32, tier: u32, metas: &[PatternMeta], cfg: TagBagConfig) -> TagBag {
        TagBag {
            rng: SplitMix32::new(seed),
            cfg,
            tier,
            themes: metas.iter().map(|m| m.theme.clone()).collect(),
            difficulty: metas.iter().map(|m| m.difficulty).collect(),
            counts: [0; ThemeTag::COUNT],
            history: Vec::new(),
            last: None,
            picks: 0,
        }
    }

    /// Draws the next pattern index out of `eligible`.
    ///
    /// `eligible` holds catalog indices the caller has already filtered by role,
    /// level and budget. Returns `None` only when `eligible` is empty or holds no
    /// index this bag knows about.
    pub fn pick(&mut self, eligible: &[usize]) -> Option<usize> {
        if eligible.is_empty() {
            return None;
        }
        let mut candidates: Vec<usize> = Vec::with_capacity(eligible.len());
        for &index in eligible {
            if index >= self.themes.len() {
                continue;
            }
            if Some(index) == self.last && eligible.len() > 1 {
                continue;
            }
            candidates.push(index);
        }
        if candidates.is_empty() {
            // Only reachable when the eligible set is a single pattern.
            for &index in eligible {
                if index < self.themes.len() {
                    candidates.push(index);
                }
            }
        }
        if candidates.is_empty() {
            return None;
        }
        let mut total: u32 = 0;
        let mut weights: Vec<u32> = Vec::with_capacity(candidates.len());
        for &index in &candidates {
            let weight = self.weight(index);
            weights.push(weight);
            total = total.saturating_add(weight);
        }
        if total == 0 {
            return None;
        }
        let mut roll = self.rng.below(total);
        let mut chosen = *candidates.last()?;
        for (slot, &weight) in weights.iter().enumerate() {
            if roll < weight {
                chosen = candidates[slot];
                break;
            }
            roll -= weight;
        }
        self.record(chosen);
        Some(chosen)
    }

    /// The last `history` picks, oldest first.
    pub fn history(&self) -> &[usize] {
        &self.history
    }

    /// How many times each theme has been picked so far, indexed by
    /// [`ThemeTag::index`].
    pub fn theme_counts(&self) -> &[u32; ThemeTag::COUNT] {
        &self.counts
    }

    /// How many picks the bag has made.
    pub fn picks(&self) -> u32 {
        self.picks
    }

    /// Integer weight of `index` under the current history and theme counts.
    fn weight(&self, index: usize) -> u32 {
        let mut weight: u32 = BASE_WEIGHT;
        for theme in &self.themes[index] {
            let used = self.counts[theme.index()];
            let missing = self.cfg.theme_target.saturating_sub(used);
            weight = weight.saturating_add(self.cfg.theme_bonus.saturating_mul(missing));
        }
        let over = u32::from(self.difficulty[index]).saturating_sub(self.tier);
        weight = weight.saturating_sub(self.cfg.difficulty_penalty.saturating_mul(over));
        if self.history.contains(&index) {
            weight /= self.cfg.recent_divisor.max(1);
        }
        weight.max(1)
    }

    /// Records a pick: history, theme counters and the last-pick guard.
    fn record(&mut self, index: usize) {
        self.last = Some(index);
        self.history.push(index);
        while self.history.len() > self.cfg.history {
            self.history.remove(0);
        }
        let counts = &mut self.counts;
        for theme in &self.themes[index] {
            let slot = &mut counts[theme.index()];
            *slot = slot.saturating_add(1);
        }
        self.picks = self.picks.saturating_add(1);
    }
}

/// The ordered list of pattern ids a level will use.
///
/// Produced from `(seed, level, players)` before any geometry is placed. Entry 0
/// is always the hub; the remaining entries are the `path`/`junction` patterns the
/// growth walk tries, in order. `indices` are catalog indices, index-aligned with
/// `ids`, so the walk can look the geometry up without a string search.
#[derive(Clone, Debug, PartialEq, Eq)]
pub struct CompositionPlan {
    seed: u32,
    level: u32,
    players: u32,
    ids: Vec<String>,
    indices: Vec<usize>,
}

impl CompositionPlan {
    /// An empty plan, used when the catalog carries no pattern metadata.
    pub fn empty(seed: u32, level: u32, players: u32) -> CompositionPlan {
        CompositionPlan {
            seed,
            level,
            players,
            ids: Vec::new(),
            indices: Vec::new(),
        }
    }

    /// Builds the plan for `(seed, level, players)` with the default plan length.
    pub fn build(metas: &[PatternMeta], seed: u32, level: u32, players: u32) -> CompositionPlan {
        CompositionPlan::build_with_len(
            metas,
            seed,
            level,
            players,
            plan_len(level),
            tier_for(level),
        )
    }

    /// Builds a plan of at most `len` entries, biased against difficulty above `tier`.
    ///
    /// The first entry is a hub with `min_level <= level`; the rest are
    /// `path`/`junction` patterns that satisfy the composition constraints in
    /// `design/PATTERN_FORMAT.md` §6. Returns an empty plan when no hub is eligible.
    pub fn build_with_len(
        metas: &[PatternMeta],
        seed: u32,
        level: u32,
        players: u32,
        len: usize,
        tier: u32,
    ) -> CompositionPlan {
        let mut plan = CompositionPlan::empty(seed, level, players);
        if metas.is_empty() || len == 0 {
            return plan;
        }
        let mut bag = TagBag::new(
            mix_seed(seed, level, players),
            tier,
            metas,
            TagBagConfig::default(),
        );
        let hubs: Vec<usize> = (0..metas.len())
            .filter(|&i| metas[i].role == ChunkRole::Hub && metas[i].min_level <= level)
            .collect();
        let Some(hub) = bag.pick(&hubs) else {
            return plan;
        };
        plan.push(hub, metas);
        let walk: Vec<usize> = (0..metas.len())
            .filter(|&i| {
                matches!(metas[i].role, ChunkRole::Path | ChunkRole::Junction)
                    && metas[i].min_level <= level
            })
            .collect();
        if walk.is_empty() {
            return plan;
        }
        while plan.len() < len {
            let previous = plan.indices.last().copied();
            let mut pool: Vec<usize> = walk
                .iter()
                .copied()
                .filter(|&i| {
                    allowed_after(previous.map(|p| &metas[p]), &metas[i])
                        && theme_run(&plan.indices, metas, i) < MAX_THEME_RUN
                })
                .collect();
            if pool.len() == 1 && Some(pool[0]) == previous {
                pool = walk.clone();
            }
            if pool.is_empty() {
                pool = walk.clone();
            }
            let Some(index) = bag.pick(&pool) else {
                break;
            };
            plan.push(index, metas);
        }
        plan
    }

    /// The seed this plan was built from.
    pub fn seed(&self) -> u32 {
        self.seed
    }

    /// The level this plan was built for.
    pub fn level(&self) -> u32 {
        self.level
    }

    /// The player count this plan was built for.
    pub fn players(&self) -> u32 {
        self.players
    }

    /// The ordered pattern ids.
    pub fn ids(&self) -> &[String] {
        &self.ids
    }

    /// The ordered catalog indices, index-aligned with [`CompositionPlan::ids`].
    pub fn indices(&self) -> &[usize] {
        &self.indices
    }

    /// Number of entries in the plan.
    pub fn len(&self) -> usize {
        self.ids.len()
    }

    /// Whether the plan has no entries.
    pub fn is_empty(&self) -> bool {
        self.ids.is_empty()
    }

    /// The catalog index of the hub, if the plan has one.
    pub fn hub_index(&self) -> Option<usize> {
        self.indices.first().copied()
    }

    /// A cursor over this plan, starting at entry 0.
    pub fn cursor(&self) -> PlanCursor<'_> {
        PlanCursor::new(self)
    }

    fn push(&mut self, index: usize, metas: &[PatternMeta]) {
        self.ids.push(metas[index].id.clone());
        self.indices.push(index);
    }
}

/// A forward-only cursor over a [`CompositionPlan`].
///
/// The growth walk asks for the next plan entry that satisfies its own placement
/// predicate; entries that do not fit are consumed and skipped, never revisited.
pub struct PlanCursor<'a> {
    plan: &'a CompositionPlan,
    position: usize,
}

impl<'a> PlanCursor<'a> {
    /// A cursor positioned at entry 0.
    pub fn new(plan: &'a CompositionPlan) -> Self {
        PlanCursor { plan, position: 0 }
    }

    /// Advances the cursor by `count` entries without yielding them.
    pub fn skip(&mut self, count: usize) {
        self.position = (self.position + count).min(self.plan.indices.len());
    }

    /// Returns the next entry accepted by `predicate`, consuming everything before it.
    pub fn next_matching(&mut self, mut predicate: impl FnMut(usize) -> bool) -> Option<usize> {
        while self.position < self.plan.indices.len() {
            let index = self.plan.indices[self.position];
            self.position += 1;
            if predicate(index) {
                return Some(index);
            }
        }
        None
    }

    /// How many entries are left, accepted or not.
    pub fn remaining(&self) -> usize {
        self.plan.indices.len().saturating_sub(self.position)
    }

    /// The current cursor position.
    pub fn position(&self) -> usize {
        self.position
    }
}

/// Whether `candidate` may directly follow `previous` under the tag-interaction
/// rules of `design/PATTERN_FORMAT.md` §6.3.
fn allowed_after(previous: Option<&PatternMeta>, candidate: &PatternMeta) -> bool {
    let Some(previous) = previous else {
        return true;
    };
    if previous.has_mechanic(MechanicTag::Rest) && candidate.has_mechanic(MechanicTag::Rest) {
        return false;
    }
    if previous.has_mechanic(MechanicTag::Gauntlet) && candidate.has_mechanic(MechanicTag::Gauntlet)
    {
        return false;
    }
    if candidate.has_mechanic(MechanicTag::Fork) && candidate.role != ChunkRole::Junction {
        return false;
    }
    if candidate.has_mechanic(MechanicTag::DeadEnd) && candidate.role != ChunkRole::DeadEnd {
        return false;
    }
    true
}

/// How many trailing entries of `chosen` share a theme with `candidate`.
fn theme_run(chosen: &[usize], metas: &[PatternMeta], candidate: usize) -> usize {
    let mut run = 0usize;
    for &index in chosen.iter().rev() {
        let shares = metas[index]
            .theme
            .iter()
            .any(|theme| metas[candidate].theme.contains(theme));
        if !shares {
            break;
        }
        run += 1;
    }
    run
}

/// Default plan length for `level`: `10 + level`, clamped to `[10, 48]`.
pub fn plan_len(level: u32) -> usize {
    (MIN_PLAN_LEN + level as usize).min(MAX_PLAN_LEN)
}

/// The plan's own difficulty tier estimate for `level`, `1..=3`.
///
/// [`crate::levelgen`] passes its authoritative `level_tier` when it builds the
/// real plan; this helper only serves callers that have nothing but a level.
pub fn tier_for(level: u32) -> u32 {
    (1 + level.saturating_sub(1) / 4).min(3)
}

/// Error returned by [`merge_catalog_json`].
#[derive(Clone, Debug, PartialEq, Eq)]
pub enum CatalogError {
    /// A source was not valid JSON.
    Json(String),
    /// A source did not have the `{ "version": 1, "chunks" | "patterns": [...] }` shape.
    Shape,
    /// Two sources declared the same pattern id.
    DuplicateId(String),
}

impl std::fmt::Display for CatalogError {
    fn fmt(&self, f: &mut std::fmt::Formatter<'_>) -> std::fmt::Result {
        match self {
            CatalogError::Json(message) => write!(f, "catalog source is not valid JSON: {message}"),
            CatalogError::Shape => write!(
                f,
                "catalog source must be {{ \"version\": 1, \"chunks\" | \"patterns\": [ ... ] }}"
            ),
            CatalogError::DuplicateId(id) => write!(f, "duplicate pattern id: {id}"),
        }
    }
}

impl std::error::Error for CatalogError {}

/// Merges the three catalog files into one `{ "version": 1, "chunks": [...] }`
/// document that the existing catalog parser can consume unchanged.
///
/// `sources` holds the raw text of `design/chunks.json`, `design/patterns-a.json`
/// and `design/patterns-b.json`, in that order. Both key names (`chunks` and
/// `patterns`) are accepted in any source, empty sources are skipped, and a
/// duplicate `id` across sources is an error — that is the check
/// `validate-content` reports.
pub fn merge_catalog_json(sources: &[&str]) -> Result<String, CatalogError> {
    let mut merged: Vec<serde_json::Value> = Vec::new();
    let mut seen: std::collections::BTreeSet<String> = std::collections::BTreeSet::new();
    for source in sources {
        if source.trim().is_empty() {
            continue;
        }
        let root: serde_json::Value =
            serde_json::from_str(source).map_err(|e| CatalogError::Json(e.to_string()))?;
        let entries = root
            .get("chunks")
            .or_else(|| root.get("patterns"))
            .and_then(serde_json::Value::as_array)
            .ok_or(CatalogError::Shape)?;
        for entry in entries {
            let id = entry
                .get("id")
                .and_then(serde_json::Value::as_str)
                .ok_or(CatalogError::Shape)?
                .to_string();
            if !seen.insert(id.clone()) {
                return Err(CatalogError::DuplicateId(id));
            }
            merged.push(entry.clone());
        }
    }
    let mut root = serde_json::Map::new();
    root.insert("version".to_string(), serde_json::Value::from(1));
    root.insert("chunks".to_string(), serde_json::Value::Array(merged));
    serde_json::to_string(&serde_json::Value::Object(root))
        .map_err(|e| CatalogError::Json(e.to_string()))
}

/// Core assembly: builds a level from `cat` with explicit budget parameters.
#[allow(clippy::too_many_arguments)]
fn assemble_level(
    cat: &Catalog,
    rng_seed: u32,
    run_seed: u32,
    level: u32,
    players: u32,
    event: u8,
    target_area_u: f32,
    max_chunks: usize,
    max_junctions_u: u32,
    spacing_mul: f32,
) -> Option<GeneratedLevel> {
    let mut rng = Rng::new(seed_mix(rng_seed, level));
    let tier = level_tier(level);
    let high_rise = event == EVENT_HIGH_RISE;

    // --- T-069 composition plan. Derived from the run seed (not the attempt seed) so every
    // regeneration attempt of one run walks the same pattern order; the geometry RNG still
    // varies per attempt. A catalog with no pattern tags yields an empty plan and the walk
    // keeps the pre-T-069 weighted picks.
    let metas = pattern_metas(cat);
    let plan = if metas.iter().any(|m| m.is_tagged()) {
        crate::pattern::CompositionPlan::build_with_len(
            &metas, run_seed, level, players, max_chunks, tier,
        )
    } else {
        crate::pattern::CompositionPlan::empty(run_seed, level, players)
    };
    let mut cursor = plan.cursor();
    cursor.skip(1); // entry 0 is the hub, placed below

    // --- hub at the origin (unrotated).
    let hub_choices: Vec<usize> = cat
        .chunks
        .iter()
        .enumerate()
        .filter(|(_, c)| c.role == ChunkRole::Hub && c.min_level <= level)
        .map(|(i, _)| i)
        .collect();
    if hub_choices.is_empty() {
        return None;
    }
    let hub_ci = match plan.hub_index() {
        Some(index) if hub_choices.contains(&index) => index,
        _ => {
            let hub_weights: Vec<f32> = hub_choices
                .iter()
                .map(|&i| chunk_weight(&cat.chunks[i], tier, false))
                .collect();
            let hub_pick = weighted_pick(&mut rng, &hub_weights)?;
            hub_choices[hub_pick]
        }
    };
    let hub_chunk = &cat.chunks[hub_ci];
    let hub_geom = build_geometry(hub_chunk, 0, Vec3::new(0.0, 0.0, 0.0));
    let beacon = hub_geom.beacon?; // hubs are guaranteed a beacon by parse_catalog
    let enemy_spawns = hub_geom.enemy_slots.clone();
    let hub_top_area = hub_geom.top_area;
    let mut gift_slots = hub_geom.gift_slots;
    let mut altar_slots = hub_geom.altar_slots;
    // Platform 0 = the hub's main platform.
    let mut hub_plats = hub_geom.platforms;
    let main_idx = main_platform_index(&hub_plats);
    hub_plats.swap(0, main_idx);

    let mut platforms: Vec<Platform> = Vec::new();
    let mut grid = CoarseGrid::new();
    let mut next_id: u16 = 0;
    commit_platforms(&mut platforms, &mut grid, hub_plats, &mut next_id)?;
    let hub_platform_count = platforms.len();
    let mut area_sum = hub_top_area;
    let mut open: Vec<OpenSocket> = hub_geom.sockets;

    // --- budget-driven random walk over open sockets. The random pick may target any open
    // socket (including earlier-placed ones); when the walk stalls (>= 8 consecutive failed
    // picks) every open socket is swept in order before the map is accepted. Per A1 the walk
    // stops accepting new failures once at least 70% of the area budget is reached.
    let mut chunk_count = 1usize;
    let mut junctions_used = 0u32;
    let mut dropped: Vec<OpenSocket> = Vec::new();
    let mut iters = 0usize;
    let mut consecutive_failures = 0u32;
    while iters < MAX_GROWTH_ITERS && chunk_count < max_chunks && area_sum < target_area_u && !open.is_empty() {
        iters += 1;
        let oi = rng.below(open.len());
        let mut placed: Option<(usize, Placement, usize)> = try_place(
            cat,
            &open[oi],
            &platforms,
            &grid,
            level,
            tier,
            high_rise,
            junctions_used,
            max_junctions_u,
            &mut rng,
            Some(&mut cursor),
        )
        .map(|(p, used)| (oi, p, used));
        if placed.is_none() && consecutive_failures >= 8 {
            for k in 0..open.len() {
                if k == oi {
                    continue;
                }
                if let Some((p, used)) = try_place(
                    cat,
                    &open[k],
                    &platforms,
                    &grid,
                    level,
                    tier,
                    high_rise,
                    junctions_used,
                    max_junctions_u,
                    &mut rng,
                    Some(&mut cursor),
                ) {
                    placed = Some((k, p, used));
                    break;
                }
            }
        }
        match placed {
            Some((k, p, used)) => {
                commit_placement(
                    &mut open,
                    k,
                    p,
                    used,
                    &mut platforms,
                    &mut grid,
                    &mut next_id,
                    &mut gift_slots,
                    &mut altar_slots,
                    &mut area_sum,
                    &mut chunk_count,
                    &mut junctions_used,
                )?;
                consecutive_failures = 0;
            }
            None => {
                consecutive_failures += 1;
                open[oi].failures = open[oi].failures.saturating_add(1);
                if open[oi].failures >= 3 {
                    let s = open.swap_remove(oi);
                    dropped.push(s);
                }
                // A1: accept the map once >= 70% of the area budget is reached and the walk
                // is stalled; remaining open sockets are bridged or sealed below.
                if consecutive_failures >= STALL_LIMIT && area_sum >= BUDGET_ACCEPT * target_area_u {
                    break;
                }
            }
        }
    }

    // --- A1: close loops with generated bridges, then seal the rest.
    open.append(&mut dropped);
    let _bridges = close_loops(&mut open, &mut platforms, &mut grid, &mut next_id)?;
    let _stubs = seal_open_sockets(cat, level, &mut rng, &mut open, &mut platforms, &mut grid, &mut next_id)?;

    // --- crumble (event) BEFORE gifts: gift filling only accepts NORMAL tops, so a crumbled
    // platform can never carry a gift and the A3 density cap stays consistent with validate.
    let spawn = spawn_point(&platforms[0].bounds, &beacon);
    let mut slot_supports = vec![false; platforms.len()];
    for (pos, _) in &gift_slots {
        let top = pos.y - 0.3;
        if let Some(i) = platform_top_under(&platforms, pos.x, pos.z, top, 0.0) {
            slot_supports[i] = true;
        }
    }
    for pos in &altar_slots {
        if let Some(i) = platform_top_under(&platforms, pos.x, pos.z, pos.y, 0.0)
            .or_else(|| platform_top_under(&platforms, pos.x, pos.z, pos.y - 0.3, 0.0))
        {
            slot_supports[i] = true;
        }
    }
    if event == EVENT_CRUMBLE {
        apply_crumble(&mut platforms, hub_platform_count, &slot_supports, run_seed, level);
    }

    // --- gifts (A3), altars (legacy).
    let fill = fill_gifts(&platforms, &gift_slots, &beacon, level, players, &mut rng, spacing_mul);
    let gifts = fill.gifts;
    let altar = choose_altar(
        &altar_slots,
        &platforms,
        &gifts,
        &spawn,
        &beacon,
        &enemy_spawns,
        run_seed,
        level,
        &mut rng,
    );
    let altars = match altar {
        Some((a, _)) => vec![a],
        None => Vec::new(),
    };

    let kill_y = platforms.iter().map(|p| p.bounds.min.y).fold(f32::INFINITY, f32::min) - 15.0;
    let data = LevelData {
        level,
        seed: run_seed,
        spawn,
        beacon,
        kill_y,
        event,
        altars,
        platforms,
        gifts,
    };
    Some(GeneratedLevel { data, enemy_spawns })
}

/// Tries to place one chunk on `anchor` (up to [`CANDIDATE_TRIALS`] picks; each pick
/// checks every socket of that chunk in all four rotations against the coarse grid).
/// Returns the placement and the index of the chunk socket that joined to `anchor`.
///
/// When `cursor` is `Some`, each pick is the next entry of the T-069 composition plan
/// that satisfies the role/level/junction predicate; entries that do not fit are
/// consumed. Once the plan is exhausted (or when `cursor` is `None`) the pick falls
/// back to today's `chunk_weight` draw, so an untagged catalog behaves exactly as
/// before.
#[allow(clippy::too_many_arguments)]
fn try_place(
    cat: &Catalog,
    anchor: &OpenSocket,
    platforms: &[Platform],
    grid: &CoarseGrid,
    level: u32,
    tier: u32,
    high_rise: bool,
    junctions_used: u32,
    max_junctions_u: u32,
    rng: &mut Rng,
    mut cursor: Option<&mut crate::pattern::PlanCursor<'_>>,
) -> Option<(Placement, usize)> {
    let eligible = |c: &Chunk| {
        c.min_level <= level
            && match c.role {
                ChunkRole::Path => true,
                ChunkRole::Junction => junctions_used < max_junctions_u,
                ChunkRole::Hub | ChunkRole::DeadEnd => false,
            }
    };
    for _ in 0..CANDIDATE_TRIALS {
        let ci = match cursor
            .as_mut()
            .and_then(|cur| cur.next_matching(|i| eligible(&cat.chunks[i])))
        {
            Some(i) => i,
            None => {
                let choices: Vec<usize> = cat
                    .chunks
                    .iter()
                    .enumerate()
                    .filter(|(_, c)| eligible(c))
                    .map(|(i, _)| i)
                    .collect();
                if choices.is_empty() {
                    return None;
                }
                let weights: Vec<f32> = choices
                    .iter()
                    .map(|&i| chunk_weight(&cat.chunks[i], tier, high_rise))
                    .collect();
                let chosen = weighted_pick(rng, &weights)?;
                choices[chosen]
            }
        };
        let chunk = &cat.chunks[ci];
        let mut valid: Vec<(Placement, usize)> = Vec::new();
        for (si, _) in chunk.sockets.iter().enumerate() {
            for turns in 0..4u32 {
                let Some(p) = plan_join(chunk, si, turns, anchor) else {
                    continue;
                };
                if placement_fits(&p, platforms, grid) {
                    valid.push((p, si));
                }
            }
        }
        if !valid.is_empty() {
            let pick = rng.below(valid.len());
            return Some(valid.swap_remove(pick));
        }
    }
    None
}

/// A geometry fingerprint: every platform box, bit-exact.

                p.bounds.max.x.to_bits(),
                p.bounds.max.y.to_bits(),
                p.bounds.max.z.to_bits(),
            )
        })
        .collect()
}

#[test]
fn composition_plans_diverge_and_never_repeat() {
    let metas = tagged_patterns();
    let mut distinct: BTreeSet<String> = BTreeSet::new();
    let mut plans = 0usize;
    let mut picks = 0usize;
    let mut immediate = 0usize;
    let mut within_six = 0usize;
    let mut theme_total = 0usize;

    for &level in &LEVELS {
        for seed in 0..PLAN_SEEDS {
            let plan = CompositionPlan::build(&metas, seed, level, 1);
            assert!(
                !plan.is_empty(),
                "empty plan for seed {seed} level {level}"
            );
            let ids = plan.ids();
            distinct.insert(ids.join(","));
            plans += 1;
            picks += ids.len();

            for pair in ids.windows(2) {
                if pair[0] == pair[1] {
                    immediate += 1;
                }
            }
            for i in 0..ids.len() {
                let end = (i + 7).min(ids.len());
                if ids[i + 1..end].iter().any(|other| other == &ids[i]) {
                    within_six += 1;
                }
            }

            let mut themes: BTreeSet<&str> = BTreeSet::new();
            for id in ids {
                if let Some(meta) = metas.iter().find(|m| &m.id == id) {
                    for theme in &meta.theme {
                        themes.insert(theme.as_str());
                    }
                }
            }
            theme_total += themes.len();
        }
    }

    let within_six_rate = within_six as f64 / picks as f64;
    let theme_average = theme_total as f64 / plans as f64;

    println!(
        "plan layer: {plans} plans, {} distinct lists, {picks} picks, \
         immediate repeats {immediate}, within-6 repeats {within_six} ({:.3}%), \
         avg distinct themes {:.2}",
        distinct.len(),
        within_six_rate * 100.0,
        theme_average
    );

    assert_eq!(immediate, 0, "the bag returned the same pattern twice in a row");
    // Uniform baseline over the 16 walk patterns is 6/16 = 37.5%; the bag's 1/32
    // recency divisor targets ~1.5%, so 5% is a generous ceiling.
    assert!(
        within_six_rate < 0.05,
        "within-6 repeat rate {within_six_rate:.4} exceeds 0.05"
    );
    assert_eq!(
        distinct.len(),
        plans,
        "two seeds produced the same ordered pattern list"
    );
    assert!(
        theme_average >= 2.0,
        "average distinct themes per level {theme_average:.2} is below 2"
    );
}

#[test]
fn generated_levels_validate_and_reproduce() {
    let mut failures = 0usize;
    let mut runs = 0usize;
    let mut geometries: BTreeSet<Vec<(u32, u32, u32, u32, u32, u32)>> = BTreeSet::new();

    for &level in &GEN_LEVELS {
        for seed in 0..GEN_SEEDS {
            let generated = generate_for_with_spacing(seed, level, 1, 1.0);
            if validate(&generated.data).is_err() {
                failures += 1;
            }
            geometries.insert(signature(&generated.data));
            runs += 1;
        }
    }

    let mut repro_checked = 0usize;
    for seed in (0..REPRO_SEEDS).map(|i| i * 7) {
        let first = generate_for_with_spacing(seed, 3, 2, 1.0);
        let second = generate_for_with_spacing(seed, 3, 2, 1.0);
        assert_eq!(
            signature(&first.data),
            signature(&second.data),
            "seed {seed} level 3 is not reproducible"
        );
        repro_checked += 1;
    }

    println!(
        "generator layer: {runs} levels, {failures} validation failures, \
         {} distinct geometries, {repro_checked} reproducible pairs",
        geometries.len()
    );

    assert_eq!(failures, 0, "{failures} generated levels failed validate");
    // The guaranteed-valid fallback layout is shared by every seed that reaches it,
    // so allow a 1% collision budget rather than demanding 100% distinct geometry.
    assert!(
        geometries.len() * 100 >= runs * 99,
        "only {} of {runs} generated levels are geometrically distinct",
        geometries.len()
    );
}
