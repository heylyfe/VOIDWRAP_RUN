# Ticket T-089: economy and flow audit (black-box, LAST)

Measure the systems the previous tickets built and report numbers. Precision over judgment: this audit
informs the owner's later balancing pass, it does not balance anything itself.

## The audit

`tools/economy-audit/run.mjs`, Node built-ins only, no new dependencies. It drives the real server
headlessly (or the sim crate through a small Rust harness if driving the server is impractical - say
which in NOTES) and prints `PASS/FAIL - <metric>` per metric, plus the raw numbers.

## Metrics

1. Gift income vs shop prices over 50 levels: is the player ever broke with nothing to buy, or does
   currency snowball trivially? Report income per level, spend per level, and the ratio.
2. Upgrade, curse and radar offering rates over 50 levels: how often each category appears.
3. Pedestal options vs registry caps across 100-level runs: how often the pool is empty (overflow),
   and how often each enemy is offered.
4. Hazard frequencies per difficulty mode.
5. Greater-curse occurrence rates.
6. Vote outcomes: how often the majority is unanimous, how often a tie occurs.

## Output

- `PASS/FAIL - <metric>` lines with the measured value and the threshold you chose, plus a summary
  table of outliers with concrete numbers.
- Exit 0 only when every metric is inside its threshold; a metric outside its threshold is a FAIL that
  names the number, not a crash.

## Output format

Complete files with `=== FILE: <path> ===` ... `=== END FILE ===`. Allowed paths: anything under
`tools/economy-audit/`.

Do not touch `server/`, `web/`, or `design/`. No new dependencies.

## Done when

The audit runs on regenerated evidence, prints concrete outlier numbers, and `just verify` stays green
with the audit skipped by default (env-gated like the other kits). Put the full numbers in NOTES.
