# Ticket T-061: Play-test capture for M3 (screenshots of every new feature)
Target: INKLING (max effort)

## Context
`tools/capture.mjs` drives the packaged game in headless Chromium (Playwright via `createRequire(web/package.json)`
+ `require("@playwright/test")`) through lobby -> level -> death -> run summary -> new lobby, saving screenshots and
failing on console errors. The lead uses the screenshots to verify releases. M3 added: huge layered maps, ~50 small
gifts, two-phase levels (collect all gifts -> collapse, golden gifts, beacon at spawn), nine reworked hunters with
telegraphs, Bulwark class, Ctrl mouse lock, collapse HUD, notices.

@include tools/capture.mjs

The server supports dev env vars: `VOIDWRAP_START_LEVEL=<n>` (start the run at level n so the lobby offers hunter
cards). The page exposes `data-testid`s used by capture.mjs (see the file). There is no cheat to collect gifts; the
capture cannot play the platformer well. Keep it simple and robust.

## Task
Add a second script `tools/capture-m3.mjs` (keep capture.mjs unchanged) with options `--url`, `--out`:
1. Lobby: choose a class (key 4 for... use the ClassPicker hotkeys 1-4: pick Bulwark = 3) on level 1, screenshot.
2. In level: wait until the world renders; take a WIDE overview screenshot by moving the camera (drag the mouse /
   use pointer-lock-free orbit if the camera allows it, otherwise just hold W for 2 s and jump) - name shots
   `m3-01-level.png`, `m3-02-moving.png`; press Ctrl and verify `document.pointerLockElement` toggles (log result).
3. Read and log from the page (via `window`-free means: query the HUD text) the gift counter "x / total" and assert
   total >= 40 on level 1.
4. A second run started at `VOIDWRAP_START_LEVEL=4` is NOT controllable from the script; instead accept a second URL
   `--url2` pointing to a server started that way: there pick 2 hunters + 1 reward by hotkeys (1, 2, 5), screenshot
   the draft incl. the shop (`m3-10-draft.png`, scroll down for `m3-11-shop.png`), Continue, wait 6 s for hunters to
   wake, take 3 screenshots 1 s apart (`m3-12..14-hunters.png`) so telegraphs/models may show.
5. Fail (exit 1) on console errors, print a summary of saved files and checks.

## Constraints
Only `tools/capture-m3.mjs` (Node 24+, ESM, no new packages). Plain, readable code.
