# Ticket T-085: difficulty modes

Four modes chosen in the lobby before a run, threaded through the registry pools, the pattern engine
and the voting system, and visible in the matchmaker lobby list.

## The modes

- **STANDARD**: a pedestal vote every level (the owner's directive), normal pools.
- **EXTREME**: harder pools, denser fog, relaxed selection caps (more copies allowed).
- **CHAOS**: a shop every level, plus a chaos-exclusive curse pool.
- **RANDOM**: a toggle that forces a random pedestal pick each level instead of a vote.

## What exists (verified)

- `server/crates/server/src/run.rs` owns run configuration; `design/content.json` has `events`.
- `design/ENEMY_REGISTRY.md` defines the pool rules; `design/PATTERN_FORMAT.md` defines theme tags.
- `server/crates/server/src/host.rs` reports `{players, level, phase, joinable}` to the matchmaker.

## Requirements

- The mode is chosen in the lobby, before the run starts, and is visible to every player.
- It flows into: the registry pool filter (caps, min levels), the pattern engine's tag weights, the
  voting system (RANDOM forces a pick), and the fog density.
- It is reported to the matchmaker so the lobby browser can show it alongside level and phase. That
  means a new field in the heartbeat body: change `protocol/schema.json` only if the client must see
  it, otherwise extend the matchmaker request struct and note it.
- Tests: each mode changes the pool as documented, RANDOM never opens a vote, and the mode survives a
  level transition.
- Doc-comment every public item.

## Output format

Complete files with `=== FILE: <path> ===` ... `=== END FILE ===`, or single functions with
`=== FN: <path> :: <name> ===` ... `=== END FN ===`. Allowed paths: `server/crates/server/src/`,
`server/crates/sim/src/`, `design/content.json`, `protocol/schema.json`.

Do not touch `web/` or `design/chunks.json`. No new dependencies.

## Done when

`cargo test -p server` passes with the new tests, clippy is clean, and the mode reaches the matchmaker
heartbeat. Put the mode parameters in NOTES.
