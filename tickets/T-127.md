# T-127 — Gift spawn safety: measure what the generator promises

**Cycle:** 13 · **Agent:** orchestrator (subordinates have no repo access) · **Status:** PASS

## Why

The owner's rule is "gifts must NEVER spawn inside a platform/jump pad/object".
`5.gift-spawn-safety` reported **5 intersecting gifts out of 755,878** and passed,
because the threshold was `0.0001` (0.01%) — 75 gifts of slack. That is the same
shape of defect T-126 found in `8.hazard_entities`: a threshold looser than the
stated intent, so the metric cannot fail on the thing it exists to catch.

## Root cause

`server/crates/sim/examples/pattern_dump.rs` re-implemented the gift body box test
with its own copies of `GIFT_BODY_HALF` / `GIFT_BODY_HEIGHT` and **no epsilon
margin**:

```rust
gx0 < b.max.x && gx1 > b.min.x && ...   // dump: touching counts as a hit
```

The generator uses `levelgen::aabb_intersect`, which requires overlap greater than
`EPS` (1 mm):

```rust
a.min.x < b.max.x - EPS && ...          // generator: touching does not count
```

So a gift resting against a platform face by less than a millimetre was rejected by
the generator and counted as a defect by the audit. The 5 "hits" were measurement
error, and the loose threshold existed to absorb them.

## Change

1. `levelgen::gift_body_aabb` and `levelgen::gift_body_clear` are now `pub`, so the
   dump calls the generator's own predicate instead of a copy. The duplicate
   constants are gone; the two definitions can no longer drift.
2. `tools/pattern-audit/run.mjs`: `GIFT_INTERSECT_RATE_MAX: 0.0001` replaced by
   `GIFT_INTERSECT_MAX: 0` — a count, not a rate, because the owner's rule is
   absolute. The metric detail now says so.

## Evidence

| | before | after |
|---|---|---|
| intersecting gifts | 5 / 755,878 | **0 / 755,878** |
| levels affected | 5 / 6,000 | **0 / 6,000** |
| threshold | <= 0.01% (75 gifts of slack) | **0** |

`5.gift-spawn-safety` PASS with threshold 0. Pattern audit 16/16.

## Tuning notes

None — this is a correctness rule, not a balance knob. If a future content change
makes a gift intersect, the audit now fails on the first one instead of the
seventy-sixth.

## Choice log

- **Shared predicate over a fixed copy.** Patching the dump's epsilon would have
  left two definitions of "gift body" in the tree. Calling the generator's function
  removes the class of bug, not the instance.
- **Count threshold over a rate.** A rate invites a slack budget. The owner said
  "never", so the gate is zero.
