### The helpers already available in `super::*`

These exist in the file's other test modules. **Re-declare the ones you need
inside `mod qa`** (they are private to each module), copying these bodies:

```rust
fn game() -> Game {
    Game::starting_at(2, 42).unwrap()
}

fn connect(game: &mut Game, id: ConnId) -> mpsc::Receiver<Vec<u8>> {
    let (tx, rx) = mpsc::channel(OUTBOX_CAPACITY);
    game.handle(GameEvent::Connected { id, out: tx });
    rx
}

fn hello(game: &mut Game, id: ConnId) {
    game.handle(GameEvent::Message {
        id,
        msg: ClientMsg::Hello {
            protocol_version: PROTOCOL_VERSION,
            name: "  tester\u{7}  ".into(),
        },
    });
}

fn drain(rx: &mut mpsc::Receiver<Vec<u8>>) -> Vec<ServerMsg> {
    let mut out = vec![];
    while let Ok(b) = rx.try_recv() {
        out.push(protocol::decode::<ServerMsg>(&b).unwrap());
    }
    out
}

fn player(g: &mut Game, id: ConnId) -> &mut Player {
    g.conns.get_mut(&id).unwrap().player.as_mut().unwrap()
}

fn vote(g: &mut Game, id: ConnId) {
    let picks = valid_picks(&g.run);
    g.handle(GameEvent::Message {
        id,
        msg: ClientMsg::DraftPick { picks },
    });
}
```

`Game::starting_at(level, seed)` is the constructor. `Game::handle(GameEvent)` and
`Game::tick()` are the two entry points. `g.run` is the `Run`; `g.run.level.gifts`,
`g.run.level.beacon`, `g.run.level_phase`, `g.run.phase`, `g.run.level_num`,
`g.run.currency`, `g.run.mode`, `g.run.permanents`, `g.run.curses` are all public.

### The sweep you must write

Write **four** tests. Each drives a full run and asserts invariants. Keep every
loop bounded (a hard iteration cap) so a bug fails the test instead of hanging it.

**1. `standard_run_reaches_level_five_without_softlock`**

- `Game::starting_at(2, 42)`, one connection, `hello`, `vote` to clear the draft.
- Loop up to 40 levels or until `g.run.phase == PHASE_OVER`:
  - Collect every normal gift by teleporting the player onto it (see the
    `full_loop_gifts_golden_beacon_back_to_lobby` pattern: set
    `p.state.pos = Vec3::new(gift.pos.x, gift.pos.y - 0.9, gift.pos.z)`,
    `p.state.vel = Vec3::ZERO`, `p.starved_ticks = 0`, then `g.tick()` and
    `drain`). Keep enemies dormant with `e.active_in = 1_000`.
  - Collect every golden gift the same way.
  - Walk the player to `g.run.level.beacon`, `g.tick()`.
  - Assert `g.run.phase == PHASE_ENEMY_DRAFT` and that `g.run.level_num` advanced.
  - `vote` to clear the next draft.
- Assert the run reached at least level 5 and never got stuck: at every step the
  phase is one of `PHASE_ENEMY_DRAFT`, `PHASE_PLAYING`, `PHASE_REWARD_DRAFT`,
  `PHASE_OVER`.

**2. `every_mode_completes_a_level`**

- For each `sim::mode::DifficultyMode::all()`, build a game, set
  `g.run.mode = mode`, and drive one full level to the beacon with the same
  collect-then-beacon loop.
- Assert the level completed in every mode and `g.run.level_num` advanced by one.
- This is the mode smoke test: a mode that cannot finish a level is broken.

**3. `eight_players_all_receive_run_state_and_can_vote`**

- Connect 8 clients (`ConnId` 1..=8), `hello` each, `vote` each.
- Assert every client's outbox produced at least one `ServerMsg::RunState`.
- Drive one level to the beacon, then assert every client received a
  `ServerMsg::RunOver` **or** a `ServerMsg::RunState` with the new level — i.e.
  nobody is silently dropped from the broadcast.
- Assert `g.conns.len() == 8` throughout.

**4. `shop_and_altars_do_not_break_the_run`**

- Drive to level 3 so the shop exists (`g.run.shop.is_some()`).
- For every item in the shop, call `ClientMsg::Buy { item }` from client 1 and
  `g.tick()`. Buying something you cannot afford must be rejected, not panic.
- Assert `g.run.currency` never underflows (it is `u32`; assert it did not wrap to
  a huge value) and the run is still in a legal phase afterwards.
- Then drive one more level to the beacon and assert it completes.

### Rules for the tests

- Every loop needs a hard cap (`for _ in 0..N`), never `while` without one.
- Assert with messages that name the level and phase, e.g.
  `assert_eq!(g.run.phase, PHASE_ENEMY_DRAFT, "level {} did not return to the draft", g.run.level_num);`
- Do not modify any non-test code. If a test reveals a real bug, **do not fix it** —
  write the assertion so it documents the bug, mark the test `#[ignore]` with a
  comment explaining what broke, and say so in NOTES.
