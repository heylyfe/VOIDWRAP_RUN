# Ticket T-041: New enemy behaviours (turret, mimic, corrupter) and crumbling tiles
Target: INKLING (max effort)

## Context
VOIDWRAP RUN: players collect gifts on floating platforms while enemies the players voted for hunt them. Today every
enemy is a flying chaser (`sim::rules`). The authoritative server steps enemies at TICK_HZ = 20 (one call per tick).
M2 adds three enemy behaviours and tiles that crumble. Protocol v6 already has `EnemyView.state` (ENEMY_DORMANT,
ENEMY_HUNTING, ENEMY_DISGUISED), `ProjectileView`, `TileState` (TILE_WARN, TILE_GONE), DEATH_PROJECTILE and
PLATFORM_CRUMBLE (a `Platform.kind`).

## Task
1. `rules.rs`: add a behaviour to `EnemyParams` (`pub behavior: u8` with constants BEHAVIOR_CHASER = 0,
   BEHAVIOR_TURRET = 1, BEHAVIOR_MIMIC = 2, BEHAVIOR_CORRUPTER = 3) plus the fields the behaviours below need
   (`fire_interval_ticks: u32`, `projectile_speed: f32`, `reveal_radius: f32`, `corrupt_interval_ticks: u32`).
   `EnemyParams::default()` stays exactly the current chaser (BEHAVIOR_CHASER; sensible defaults for the new fields).
   Add `pub fn enemy_state(enemy: &Enemy) -> u8` returning ENEMY_DORMANT / ENEMY_HUNTING / ENEMY_DISGUISED.
   Existing tests must keep passing (update struct literals in them only by adding `..EnemyParams::default()`).
2. New module `hazards.rs` (add `pub mod hazards;` to `lib.rs`) with a `Hazards` struct owning projectiles and tile
   state, and pure functions the server calls once per tick:
   - TURRET: never moves (stays at `home`). After its grace period, when the nearest target is within `aggro`, it
     fires one projectile every `fire_interval_ticks` toward that target's centre (feet + 0.9 up) at
     `projectile_speed` units/s. Projectiles fly straight, are removed when they enter a solid platform, after
     PROJECTILE_LIFETIME_TICKS (80) or beyond the level's kill_y, and kill a player when within PROJECTILE_RADIUS
     (0.35) of the player box (closest-point test, like `enemy_touches`). At most MAX_PROJECTILES (64) alive; ids
     increase monotonically (u32, wrapping).
   - MIMIC: sits still at `home` looking like a gift (ENEMY_DISGUISED, harmless) until any target comes within
     `reveal_radius`; from then on it is a chaser (ENEMY_HUNTING) using its speed/aggro and never disguises again.
     The grace period does not apply to mimics.
   - CORRUPTER: a chaser (half its configured speed while corrupting is not needed - keep chaser movement) that,
     after its grace period, every `corrupt_interval_ticks` marks the solid platform whose top-face centre is nearest
     to it as WARN, never the platform with id 0 (the spawn) and never the platform whose top contains the beacon.
   - TILES: platforms of kind PLATFORM_CRUMBLE that a player stands on (feet inside the top rectangle in x/z and
     |feet.y - top| <= 0.05) become WARN. WARN lasts TILE_WARN_TICKS (12), then GONE for TILE_GONE_TICKS (60), then
     back to normal. Corrupted platforms follow the same WARN -> GONE -> normal cycle (any platform kind).
     `tiles(&self) -> Vec<TileState>` lists only non-normal platforms, sorted by id.
   Suggested API (adjust if needed, document it in NOTES):
   `Hazards::new()`, `Hazards::reset(&mut self)` (new level),
   `Hazards::step(&mut self, enemies: &mut [Enemy], world: &World, level: &LevelData, players: &[Vec3])`
   (players = feet of living players; also steps chaser/mimic/corrupter movement, replacing the server's call to
   `step_enemy` for all enemies), `Hazards::hit(&self, enemies: &[Enemy], feet: &Vec3) -> Option<u8>` returning
   DEATH_ENEMY for an active non-disguised enemy touch or DEATH_PROJECTILE, `Hazards::projectiles() -> Vec<ProjectileView>`,
   `Hazards::tiles() -> Vec<TileState>`. The server will call `world.set_tiles(&hazards.tiles())` after `step` (that
   World method is being added in another ticket - do not call it yourself).
3. Tests for every rule: turret fire cadence and aim, projectile hits / wall removal / lifetime, mimic reveal and
   harmless while disguised, corrupter never picks spawn or beacon platform, crumble timing, tiles() ordering,
   default params unchanged.
