## Part 1 - the trampoline (a platform kind, like the jump pad)

`sim/src/tuning.rs` gains, next to `PAD_LAUNCH_VEL`:

```rust
/// PLATFORM_TRAMPOLINE: vertical launch velocity applied on contact (units/s). Higher than a jump
/// pad so it opens vertical routes a pad cannot.
pub const TRAMPOLINE_LAUNCH_VEL: f32 = 26.0;
/// PLATFORM_TRAMPOLINE: multiplier applied to horizontal velocity on launch. Above 1.0 so the arc
/// carries further than the run-up, unlike a pad which kills horizontal speed.
pub const TRAMPOLINE_HORIZONTAL_VEL_MUL: f32 = 1.15;
```

`sim/src/controller.rs`: replace `launch_pad_if_contact` so it handles both kinds. Current body
(verbatim):

```rust
fn launch_pad_if_contact(state: &mut ControllerState, world: &World, movement_locked: bool) -> bool {
    if movement_locked {
        return false;
    }
    let Some(index) = standing_platform(state, world) else {
        return false;
    };
    let is_pad = world
        .platforms
        .get(index)
        .map(|p| p.kind == protocol::PLATFORM_JUMP_PAD)
        .unwrap_or(false);
    if !is_pad {
        return false;
    }
    state.vel.y = PAD_LAUNCH_VEL;
    state.vel.x *= PAD_HORIZONTAL_VEL_MUL;
    state.vel.z *= PAD_HORIZONTAL_VEL_MUL;
    true
}
```

Rewrite it to read the kind once and pick the (vertical, horizontal) pair: `PLATFORM_JUMP_PAD` ->
`(PAD_LAUNCH_VEL, PAD_HORIZONTAL_VEL_MUL)`, `PLATFORM_TRAMPOLINE` ->
`(TRAMPOLINE_LAUNCH_VEL, TRAMPOLINE_HORIZONTAL_VEL_MUL)`, anything else -> `false`. Keep the
`movement_locked` early-out, the `standing_platform` lookup and the "launch once per contact" property
(the launch leaves the player airborne, so a repeat needs a new landing). Update the doc comment to
cover both kinds.

## Part 2 - the tripmine (`sim/src/tripmine.rs`, new file, complete)

A tripmine is a ground hazard with three phases: it arms over a short window (the visible telegraph),
fires once when a player is inside its radius, then disarms for a while so the route reopens behind
whoever set it off. Pure logic, no server deps, wasm-safe. Doc-comment every public item. Add
`pub mod tripmine;` to `lib.rs` in alphabetical order (after `rules`, before `tuning`).

```rust
//! Tripmines (T-087): arm, fire once, then reopen the route.

/// Radius that triggers a tripmine, in units.
pub const TRIPMINE_RADIUS: f32 = 1.6;
/// Ticks a fresh tripmine spends arming (2.0 s at 20 Hz) - the visible telegraph.
pub const TRIPMINE_ARM_TICKS: u32 = 40;
/// Ticks a tripmine stays disarmed after firing (6.0 s at 20 Hz).
pub const TRIPMINE_DISARM_TICKS: u32 = 120;

/// What a tripmine is doing right now.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum TripminePhase { Arming, Armed, Disarmed }

/// One tripmine's state.
#[derive(Debug, Clone, Copy, PartialEq, Eq, Default)]
pub struct Tripmine { /* phase: TripminePhase, ticks: u32 */ }

impl Tripmine {
    /// A fresh tripmine, arming.
    pub fn new() -> Tripmine;
    /// What it is doing right now.
    pub fn phase(&self) -> TripminePhase;
    /// Ticks left in the current phase (0 when armed and waiting).
    pub fn ticks_left(&self) -> u32;
    /// True only while armed: the phase in which it can fire.
    pub fn is_armed(&self) -> bool;
    /// Advance one tick: Arming -> Armed, Disarmed -> Arming.
    pub fn tick(&mut self);
    /// Fire if armed. Returns true when it actually fired (and is now disarmed).
    pub fn trigger(&mut self) -> bool;
}
```

Tests: a fresh mine is `Arming` and not armed; it becomes `Armed` after exactly `TRIPMINE_ARM_TICKS`
ticks; `trigger` on an arming or disarmed mine returns false and changes nothing; `trigger` on an
armed mine returns true and moves it to `Disarmed`; it re-arms after `TRIPMINE_DISARM_TICKS`; a second
`trigger` while disarmed returns false.

## Part 3 - the two curse options

`design/content.json`: append two entries to the `curses` array (after `hush`, before the closing `]`).
`effect` <= 60 chars, `flavor` <= 70, `rarity` is `"common"` or `"rare"` only, `threat` is 1..5.

```json
    {
      "id": "more_trampolines",
      "name": "Spring Floor",
      "flavor": "The ground has decided to throw you somewhere else.",
      "effect": "more trampolines in every generated level",
      "rarity": "rare",
      "threat": 3,
      "greater": false,
      "mods": { "gravity_mul": 1.05 }
    },
    {
      "id": "minefield",
      "name": "Minefield",
      "flavor": "Someone has been very busy under the floorboards.",
      "effect": "tripmines appear in every generated level",
      "rarity": "rare",
      "threat": 4,
      "greater": false,
      "mods": { "enemy_aggro_mul": 1.1 }
    }
```

The `mods` are deliberately mild: the hazard frequency is the real cost, and the validator requires a
non-empty mod map on a non-greater curse.
